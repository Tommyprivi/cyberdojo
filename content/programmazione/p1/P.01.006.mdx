<Scene title="Maggiorenni a tavola">
Elia organizza una serata di giochi da tavolo nella pizzeria, riservata ai maggiorenni. Un'amica, Sara, gli dice: «Devi far entrare solo chi ha 18 anni o più». Elia pensa: «La domanda "ha 18 anni o più?" ha una risposta sola: sì oppure no».

Proprio così: tutte le decisioni dei programmi si riducono a domande con due sole risposte.

La domanda del caso: **come ragiona un computer quando deve decidere?**

<Say who="sensei">Un computer non ha dubbi: ogni condizione per lui è vera oppure falsa.</Say>
</Scene>

<Scene title="Vero e falso">
Una **condizione** è un'affermazione che può essere **vera** o **falsa**, mai una via di mezzo. Esempi:

- «L'età è almeno 18» con età 20: **vero**.
- «L'età è almeno 18» con età 16: **falso**.
- «Il cliente ha pagato» quando non ha pagato: **falso**.

I due valori «vero» e «falso» si chiamano **valori booleani**, dal nome del matematico inglese George Boole (1815-1864), che nell'Ottocento studiò la logica con regole matematiche. La **logica booleana** è la base di tutti i computer.

<Callout kind="curiosita">
Nei linguaggi di programmazione i valori booleani hanno nomi propri. In Python si scrivono `True` e `False`, con l'iniziale maiuscola.
</Callout>

<Say who="assistente">Una condizione è una domanda che ha una sola risposta giusta: sì o no, vero o falso.</Say>
</Scene>

{/* screen */}

<Scene title="I confronti">
Per costruire le condizioni si **confrontano** due valori. Ecco i sei confronti principali:

<Layers
  caption="I confronti più usati."
  items={[
    { icon: "check", title: "uguale a", text: "In Python si scrive con due segni ==" },
    { icon: "cross", title: "diverso da", text: "In Python si scrive !=" },
    { icon: "chart", title: "maggiore / minore", text: "Si scrivono con i segni di maggiore e minore" },
    { icon: "bolt", title: "maggiore o uguale / minore o uguale", text: "Includono anche il valore stesso: >= e <=" },
  ]}
/>

Con `eta = 18`:
- `eta >= 18` è **vero** (18 è uguale a 18).
- `eta > 18` è **falso** (18 non è maggiore di 18).
- `eta == 18` è **vero**.
- `eta != 18` è **falso**.

<Callout kind="attenzione">
Il confine è la parte più insidiosa. «Più di 18» esclude il 18, «almeno 18» lo include. Nelle regole, ogni parola conta: leggile con calma.
</Callout>

<Say who="sensei">La maggior parte dei bug nelle condizioni sta nel confine: uguale o no.</Say>
</Scene>

{/* screen */}

<Scene title="Un segno, due significati">
In molti linguaggi, Python compreso, il segno `=` e il doppio segno `==` fanno cose diverse:

```python
eta = 20          # assegnazione: metti 20 nella scatola eta
eta == 20         # confronto: eta è uguale a 20? Risposta: True
eta == 18         # confronto: eta è uguale a 18? Risposta: False
```

- `=` **cambia** il contenuto di una scatola.
- `==` **chiede** se due valori sono uguali, senza cambiare niente.

Confonderli è uno dei primi errori di chi comincia. Se leggi `=` pensa «diventa», se leggi `==` pensa «è uguale a?».

<Callout kind="regola">
Un confronto **non cambia niente**: restituisce solo vero o falso. Per cambiare una variabile serve un'assegnazione.
</Callout>

<Say who="assistente">Due segni uguali, una domanda. Un segno solo, un ordine.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- Una condizione è sempre vera o falsa: sono i valori booleani, da George Boole.
- I confronti sono uguale, diverso, maggiore, minore, maggiore o uguale, minore o uguale.
- Attenzione al confine: «più di 18» esclude il 18, «almeno 18» lo include.
- In Python `=` assegna un valore, `==` confronta due valori.
- Caso chiuso: per far entrare chi ha 18 anni o più, la condizione è «età maggiore o uguale a 18».
</Recap>
