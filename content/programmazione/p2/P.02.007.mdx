Giulia ora sa stampare un saluto. Ma i 40 iscritti sono 40 saluti: scrivere 40 `print` sarebbe lo stesso lavoro noioso di prima. Serve un modo per dire al computer: «ripeti questa cosa finché serve».

Questa idea l'hai già incontrata nel modulo di logica: il **ciclo**. Oggi lo scrivi in Python con `while`, che significa «finché».

La domanda del caso: **come si fa ripetere un'azione molte volte senza riscriverla?**

<Scene title="La forma del while">
```python
n = 1
while n <= 3:
    print("Iscritto numero", n)
    n = n + 1
print("Fine")
```

- Il `while` controlla la condizione **prima** di ogni giro.
- Se è vera, esegue il blocco rientrato e poi **torna a controllare**.
- Quando diventa falsa, il ciclo finisce e Python passa alla riga dopo (qui `print("Fine")`, che non è rientrata).

Traccia dei valori di `n`: parte da 1, poi 2, poi 3, poi 4. Con `n = 4` la condizione `4 <= 3` è falsa e il ciclo si ferma: sono stati fatti 3 giri.

<Say who="assistente">Come nella traccia d'esecuzione: segna su un foglio il valore di n a ogni giro e vedrai esattamente che cosa succede.</Say>

<Scene title="Il contatore e il ciclo infinito">
Nel ciclo di prima c'è una variabile, `n`, che fa da **contatore**: parte da un valore, cambia a ogni giro e fa diventare falsa la condizione. Tre cose da avere sempre:

1. **Inizializzazione**: dare un valore di partenza (`n = 1`).
2. **Condizione**: la domanda che decide se continuare (`n <= 3`).
3. **Aggiornamento**: cambiare la variabile dentro il ciclo (`n = n + 1`).

Se dimentichi l'aggiornamento succede questo:

```python
n = 1
while n <= 3:
    print("Iscritto numero", n)
```

`n` resta sempre 1, la condizione è sempre vera e il programma stampa all'infinito: un **ciclo infinito**.

<Callout kind="attenzione">
Se il programma non si ferma più, premi **Ctrl + C** nel terminale: Python viene interrotto. Poi cerca la riga che dovrebbe far cambiare la condizione.
</Callout>

Un altro errore frequente è sbagliare di uno: con `while n < 3` il ciclo gira solo per 1 e 2, cioè 2 volte. Per i 3 giri serve `<= 3`.

<Say who="sensei">Un ciclo infinito non è un guasto del computer. È una condizione che non diventa mai falsa. Cercala.</Say>
</Scene>

<Scene title="Chiedere finché non va bene">
Il `while` è perfetto quando **non sai quante volte** dovrai ripetere. Giulia vuole chiedere un punteggio valido, tra 0 e 10:

```python
punti = int(input("Punti (0-10)? "))
while punti < 0 or punti > 10:
    print("Valore non valido")
    punti = int(input("Punti (0-10)? "))
print("Registrati", punti, "punti")
```

<Log lines={[
  "Punti (0-10)? 15",
  "Valore non valido",
  "Punti (0-10)? 7",
  "Registrati 7 punti",
]} caption="Chiede di nuovo finché il valore è tra 0 e 10." />

Con `break` si può uscire subito da un ciclo, anche se la condizione è ancora vera. Questo programma si ferma quando scrivi `0`:

```python
somma = 0
while True:
    n = int(input("Numero (0 per finire): "))
    if n == 0:
        break
    somma = somma + n
print("Somma:", somma)
```

`while True` è una condizione sempre vera: il ciclo si ferma solo grazie al `break`.

<Say who="assistente">Il break è come l'uscita di emergenza: ti permette di decidere dentro il ciclo quando basta.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- while ripete un blocco finché la condizione è vera, controllandola prima di ogni giro.
- Servono un valore di partenza, una condizione e un aggiornamento dentro il ciclo.
- Senza aggiornamento il ciclo è infinito: si interrompe con Ctrl + C.
- break esce subito dal ciclo; while True con break è un modo per «ripeti finché non dico basta».
