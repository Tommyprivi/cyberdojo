<Scene title="if ed else">
Una **condizione** è una domanda a cui si risponde `True` o `False`. Per farla si usano i **confronti**:

<Layers
  caption="Gli operatori di confronto."
  items={[
    { icon: "check", title: "==  e  !=", text: "Uguale a, diverso da" },
    { icon: "chart", title: "<  e  >", text: "Minore di, maggiore di" },
    { icon: "chart", title: "<=  e  >=", text: "Minore o uguale, maggiore o uguale" },
  ]}
/>

Con `if` («se») si esegue un blocco solo quando la condizione è vera; con `else` («altrimenti») si dice che cosa fare negli altri casi:

```python
punti = int(input("Punti? "))
if punti >= 5:
    print("Sei in finale")
else:
    print("Torneo finito")
```

Tre dettagli che fanno la differenza:
- Dopo la condizione ci sono i **due punti** `:`.
- Le righe dentro il blocco sono **rientrate** (4 spazi): è l'indentazione che dice a Python quali righe appartengono all'`if`.
- Il confronto di uguaglianza è `==` con due uguali; un solo `=` assegna.

<Callout kind="attenzione">
`if punti = 5:` dà errore di sintassi. Per confrontare scrivi `if punti == 5:`.
</Callout>

<Say who="assistente">L'indentazione in Python non è estetica: è parte del linguaggio. Se la sbagli, il programma fa altro.</Say>
</Scene>

<Scene title="Più strade con elif">
Per più di due strade c'è `elif` (da *else if*, «altrimenti se»). Python controlla le condizioni **in ordine** e si ferma alla prima vera:

```python
punti = int(input("Punti? "))
if punti >= 8:
    print("Hai vinto il torneo")
elif punti >= 5:
    print("Sei in finale")
else:
    print("Hai chiuso il torneo")
```

<Flow

  steps={[
    { icon: "search", title: "punti >= 8?", text: "Se sì: Hai vinto il torneo" },
    { icon: "search", title: "punti >= 5?", text: "Se sì: Sei in finale" },
    { icon: "check", title: "Altrimenti", text: "Hai chiuso il torneo" },
  ]}
/>

<Log lines={[
  "Con 9 punti: Hai vinto il torneo",
  "Con 6 punti: Sei in finale",
  "Con 2 punti: Hai chiuso il torneo",
]} caption="Che cosa stampa il programma." />

Con 9 punti la prima condizione è vera, quindi le altre non vengono nemmeno controllate. Con 6 la prima è falsa, la seconda è vera. L'`else` finale prende tutto il resto. Per questo l'ordine conta: se metti `punti >= 5` per primo, chi ha 9 punti leggerà «Sei in finale».

<Say who="sensei">Dalla condizione più stretta alla più larga. L'ordine delle strade è parte del programma.</Say>
</Scene>

<Scene title="and, or, not">
Le condizioni si combinano con gli operatori logici della lezione di logica:

- `and`: vero se **entrambe** sono vere.
- `or`: vero se **almeno una** è vera.
- `not`: rovescia il valore.

```python
eta = 15
iscritto = True
if eta >= 14 and iscritto:
    print("Puoi giocare")
if eta < 14 or not iscritto:
    print("Controlla l'iscrizione")
```

Qui `eta >= 14 and iscritto` è vero (15 è almeno 14 e `iscritto` è `True`), quindi stampa «Puoi giocare». La seconda condizione è falsa: `eta < 14` è falso e `not iscritto` è falso, quindi non stampa niente.

<Callout kind="trucco">
Un `if` può stare dentro un altro `if`, rientrando ancora di 4 spazi. Ma spesso `and` rende il codice più corto e leggibile.
</Callout>

Per controllare più valori si possono anche **concatenare** i confronti: `5 <= punti < 8` è vero quando `punti` è 5, 6 o 7 (se è intero).

<Say who="assistente">Se non ricordi la tabella di verità di and e or, rivedi il modulo di logica: serve proprio qui.</Say>
</Scene>

<Recap xp={20}>
- if esegue un blocco solo se la condizione è vera, else prende gli altri casi, elif aggiunge strade intermedie.
- I confronti sono == != < > <= >=; con un solo = si assegna, non si confronta.
- Dopo la condizione servono i due punti e il blocco va rientrato di 4 spazi.
- Python controlla in ordine e si ferma alla prima condizione vera: l'ordine conta.
- Caso chiuso: il programma di Giulia risponde in tre modi diversi in base ai punti del giocatore.
</Recap>
