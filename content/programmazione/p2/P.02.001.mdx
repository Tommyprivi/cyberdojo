<Scene title="Il primo saluto">
Giulia, 15 anni, organizza il torneo di scacchi della sua scuola. Ha un elenco di 40 iscritti e vorrebbe che il computer stampasse un saluto per ognuno, invece di scriverli a mano.

Per dare ordini al computer serve un linguaggio. Noi useremo **Python**: è semplice da leggere, gratuito e usato in tutto il mondo. Un **programma** è un file di testo con istruzioni che Python esegue una dopo l'altra, dall'alto in basso.

La domanda del caso: **come si fa stampare una frase al computer?**

<Say who="sensei">Una riga di Python è un ordine. Il computer lo esegue alla lettera, senza interpretare. Per questo bisogna scriverlo giusto.</Say>
</Scene>

<Scene title="Installare Python">
Python è gratuito. Si scarica dal sito ufficiale **python.org** (sezione Downloads). Scegli sempre Python **3**.

<Layers
  caption="Che cosa serve per cominciare."
  items={[
    { icon: "terminal", title: "Il terminale", text: "Dove si lanciano i comandi" },
    { icon: "code", title: "Un editor", text: "Dove si scrive il codice (va bene anche IDLE, che arriva con Python)" },
    { icon: "gear", title: "Python", text: "L'interprete che esegue le istruzioni" },
  ]}
/>

- **Windows:** nella prima schermata dell'installazione spunta la casella **Add python.exe to PATH**, poi premi Install Now. Così il terminale trova Python.
- **macOS:** apri il pacchetto scaricato da python.org e segui i passi.
- **Linux:** Python 3 spesso è già presente.

Per controllare che sia andato tutto bene, apri il terminale e scrivi:

```bash
python --version
```

Su macOS e Linux il comando è spesso `python3 --version`. Se vedi una scritta come `Python 3.x.y`, funziona. Non vuoi installare nulla? Nella sezione Pratica di CyberDojo c'è un terminale Python che funziona nel browser.

<Say who="assistente">Se il terminale dice che non trova Python, di solito è la casella PATH dimenticata. Basta rifare l'installazione spuntandola.</Say>
</Scene>

<Scene title="Il comando print">
Crea un file chiamato `saluto.py` e scrivi dentro una riga:

```python
print("Ciao, Giulia!")
```

Lo esegui dal terminale, nella cartella del file:

```bash
python saluto.py
```

<Log lines={[
  "Ciao, Giulia!",
]} caption="Che cosa compare sullo schermo." />

- `print` è una **funzione**: un comando già pronto che stampa sullo schermo.
- Le **parentesi** contengono ciò che vuoi stampare.
- Il testo sta tra **virgolette**, doppie o singole: `"ciao"` e `'ciao'` sono uguali. Un testo si chiama **stringa**.

/>

<Say who="sensei">Dall'alto in basso, una riga alla volta. Se un giorno il programma ti sorprende, torna a questa regola.</Say>
</Scene>

<Scene title="Più righe, più trucchi">
Ogni `print` va a capo da solo. Con più `print` ottieni più righe:

```python
print("Torneo di scacchi")
print("Iscrizioni aperte")
print("Ciao", "Giulia", 15)
```

<Log lines={[
  "Torneo di scacchi",
  "Iscrizioni aperte",
  "Ciao Giulia 15",
]} caption="Con la virgola, print mette uno spazio tra i pezzi." />

- Il testo va tra virgolette, i **numeri** no: `15`, non `"15"`.
- Una riga che comincia con `#` è un **commento**: Python la ignora. Serve a spiegare il codice a chi lo legge.

<Callout kind="attenzione">
Python distingue **maiuscole e minuscole**: `print` funziona, `Print` no. E ogni virgoletta aperta va chiusa, ogni parentesi aperta va chiusa.
</Callout>

Se sbagli, Python non esegue il programma e ti dice dove: per esempio `SyntaxError` significa «errore di scrittura». Leggi il messaggio: indica la riga e quasi sempre il problema.

<Say who="assistente">Gli errori non sono un giudizio su di te. Sono indizi: il computer ti sta dicendo dove guardare.</Say>
</Scene>
