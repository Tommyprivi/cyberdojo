<Scene title="Gli operatori">
Gli **operatori** sono i simboli dei calcoli:

<Layers
  caption="Gli operatori aritmetici di Python."
  items={[
    { icon: "bolt", title: "+  e  -", text: "Somma e sottrazione" },
    { icon: "bolt", title: "*  e  /", text: "Moltiplicazione e divisione (/ dà sempre un decimale)" },
    { icon: "bolt", title: "//  e  %", text: "Divisione intera e resto" },
    { icon: "bolt", title: "**", text: "Potenza" },
  ]}
/>

```python
print(7 + 2)    # 9
print(7 / 2)    # 3.5
print(7 // 2)   # 3
print(7 % 2)    # 1
print(2 ** 3)   # 8
```

- `/` è la divisione normale e dà sempre un float: anche `6 / 2` dà `3.0`.
- `//` è la divisione **intera**: scarta i decimali. `7 // 2` è `3`.
- `%` è il **resto** della divisione: `7 % 2` è `1`, perché 7 = 3 volte 2 più 1.
- `**` è la potenza: `2 ** 3` significa 2 per 2 per 2, cioè `8`. Il simbolo `^` in Python fa un'altra cosa, quindi non usarlo per le potenze.

<Callout kind="trucco">
Il resto `%` è utilissimo: `n % 2 == 0` è vero se `n` è pari. Con `%` si controlla anche se un numero è multiplo di un altro.
</Callout>

<Say who="assistente">Il resto è la parte che «avanza»: 7 caramelle divise tra 2 amici, 3 a testa e 1 che avanza.</Say>
</Scene>

<Scene title="La precedenza">
Quando in un'espressione ci sono più operatori, Python segue un ordine, dal più forte al più debole:

<Flow
  caption="L'ordine di esecuzione."
  steps={[
    { icon: "code", title: "1. Parentesi", text: "Si calcola prima ciò che sta dentro" },
    { icon: "bolt", title: "2. Potenza", text: "**" },
    { icon: "gear", title: "3. Per e diviso", text: "* / // % da sinistra a destra" },
    { icon: "check", title: "4. Più e meno", text: "+ - da sinistra a destra" },
  ]}
/>

Esempi, passo per passo:

```python
print(3 * 6 + 2)      # 18 + 2 = 20
print(3 * (6 + 2))    # 3 * 8 = 24
print(2 + 3 * 4)      # 2 + 12 = 14
print(10 - 4 - 3)     # 6 - 3 = 3
print(2 * 3 ** 2)     # 2 * 9 = 18
```

Ecco il mistero della pizzeria: nel primo caso la moltiplicazione va prima della somma, nel secondo le parentesi forzano a sommare prima. Quando due operatori hanno la stessa forza, si va da sinistra a destra: `10 - 4 - 3` è `6 - 3`, quindi `3`.

<Callout kind="regola">
Il dubbio si risolve con le parentesi. Anche quando non servono, le parentesi rendono chiaro che cosa intendevi: meglio una parentesi in più che un errore nascosto.
</Callout>

<Say who="sensei">Moltiplicazioni prima, somme dopo. Le parentesi comandano su tutto.</Say>

<Scene title="Calcoli con le variabili">
Gli stessi operatori funzionano con le variabili. Giulia calcola il costo a testa:

```python
pizze = 3
prezzo = 6
bibita = 2
totale = pizze * prezzo + bibita
amici = 4
print("Totale:", totale)
print("A testa:", totale / amici)
print("Interi per testa:", totale // amici)
print("Euro che avanzano:", totale % amici)
```

<Log lines={[
  "Totale: 20",
  "A testa: 5.0",
  "Interi per testa: 5",
  "Euro che avanzano: 0",
]} caption="20 diviso 4 fa esattamente 5." />

Controllo: `3 * 6 + 2` fa 20; `20 / 4` fa `5.0` (la divisione `/` dà un float); `20 // 4` fa `5`; `20 % 4` fa `0`.

Esiste anche una forma abbreviata per cambiare una variabile: `totale += 5` equivale a `totale = totale + 5`. Funziona anche con `-=`, `*=` e gli altri.

<Scene title="Rapporto finale">
<Recap xp={20}>
- Gli operatori sono + - * / // % e **: la divisione / dà sempre un decimale, // scarta i decimali, % dà il resto.
- La precedenza: parentesi, poi potenza, poi per e diviso, poi più e meno.
- A parità di forza si va da sinistra a destra.
- Con le parentesi si dice chiaramente in che ordine fare i calcoli.
- Caso chiuso: 3 * 6 + 2 fa 20 e 3 * (6 + 2) fa 24, perché le parentesi cambiano l'ordine.
</Recap>
