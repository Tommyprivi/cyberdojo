<Scene title="Caricare e salvare">
```python
import csv
from pathlib import Path

FILE = Path("spese.csv")
CAMPI = ["data", "categoria", "importo"]

def carica():
    if not FILE.exists():
        return []
    with open(FILE, newline="", encoding="utf-8") as f:
        return list(csv.DictReader(f))

def salva(spese):
    with open(FILE, "w", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=CAMPI)
        w.writeheader()
        w.writerows(spese)
```

- `carica` gestisce il caso «file non ancora creato» restituendo una lista vuota.
- `salva` usa la modalità `"w"`, e va bene: riscrive **tutte** le spese, quelle vecchie (già caricate in memoria) più le nuove. Se si dimentica di caricarle prima, si perdono.

<Callout kind="regola">
Il ciclo è sempre lo stesso: **carica**, cambia la lista in memoria, **salva**. Non scrivere mai su file senza aver letto prima quello che c'è.
</Callout>

<Say who="sensei">Dove c'è «w» chiediti sempre: i dati vecchi sono al sicuro? Qui sì, perché li carichiamo prima.</Say>

<Scene title="Controllare i dati">
```python
def nuova_spesa(data, categoria, testo_importo):
    try:
        importo = float(testo_importo.replace(",", "."))
    except ValueError:
        raise ValueError("Importo non valido: " + testo_importo)
    if importo <= 0:
        raise ValueError("L'importo deve essere positivo")
    return {"data": data, "categoria": categoria,
            "importo": f"{importo:.2f}"}

def totali_per_categoria(spese):
    totali = {}
    for s in spese:
        c = s["categoria"]
        totali[c] = totali.get(c, 0) + float(s["importo"])
    return totali
```

- `.replace(",", ".")` permette di scrivere `12,50` come si fa in italiano.
- `float("abc")` solleva `ValueError`: la funzione lo trasforma in un messaggio più chiaro con `raise`.
- `f"{importo:.2f}"` scrive il numero con due decimali (`12.5` diventa `12.50`).
- `totali.get(c, 0)` dà il totale già calcolato per quella categoria, oppure 0 se è la prima volta.

<Scene title="Mettere insieme">
```python
spese = carica()
try:
    spese.append(nuova_spesa("2026-03-01", "cibo", "12,50"))
    spese.append(nuova_spesa("2026-03-02", "treno", "3,20"))
except ValueError as errore:
    print("Errore:", errore)
salva(spese)

for cat, tot in totali_per_categoria(spese).items():
    print(cat, f"{tot:.2f}")
```
