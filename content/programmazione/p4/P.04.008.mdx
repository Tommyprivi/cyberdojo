<Scene title="Che cos'è il JSON">
**JSON** (*JavaScript Object Notation*) è un formato di testo per scambiare dati. Lo usano quasi tutti i linguaggi e quasi tutti i servizi su internet. Somiglia molto ai dizionari e alle liste di Python.

```json
{
  "nome": "Anna",
  "eta": 17,
  "ruoli": ["Giulietta", "Narratrice"],
  "tesserata": true,
  "note": null
}
```

I tipi che esistono in JSON:
- **oggetto** `{ }`: coppie chiave e valore, come un dizionario;
- **array** `[ ]`: un elenco, come una lista;
- **stringa** tra doppi apici, **numero**, **true** e **false**, **null** (nessun valore).

<Callout kind="attenzione">
Il JSON è più rigido di Python: le stringhe vogliono **doppi apici** (mai singoli), le chiavi sono sempre stringhe, non si possono scrivere commenti e non si può mettere una virgola dopo l'ultimo elemento.
</Callout>

<Say who="assistente">Se hai capito liste e dizionari, hai già capito il JSON. Cambiano solo alcuni nomi.</Say>
</Scene>

<Scene title="Python e JSON">
Il modulo `json` converte in entrambe le direzioni.

<Compare
  caption="Come si traducono i tipi."
  left={{ title: "Python", points: ["dict", "list e tuple", "str, int, float", "True, False", "None"] }}

```python
import json

scheda = {"nome": "Anna", "eta": 17, "ruoli": ["Giulietta"]}
testo = json.dumps(scheda)
print(testo)
print(json.loads(testo)["nome"])
```

<Log lines={[
  "{\"nome\": \"Anna\", \"eta\": 17, \"ruoli\": [\"Giulietta\"]}",
  "Anna",
]} caption="dumps trasforma in testo, loads lo trasforma di nuovo in dizionario." />

La **s** finale sta per *string*: `dumps` e `loads` lavorano con stringhe; `dump` e `load` lavorano con file.

<Scene title="Salvare e rileggere">
```python
import json

attori = [{"nome": "Anna", "eta": 17}, {"nome": "Marco", "eta": 16}]

with open("attori.json", "w", encoding="utf-8") as f:
    json.dump(attori, f, ensure_ascii=False, indent=2)

with open("attori.json", encoding="utf-8") as f:
    letti = json.load(f)
print(letti[1]["nome"])
```

- `indent=2` scrive il file con rientri, così si legge bene.
- `ensure_ascii=False` lascia le lettere accentate come sono: senza, «è» diventa `è`, valido ma illeggibile.
- `json.load(f)` restituisce di nuovo liste e dizionari: l'ultima riga stampa `Marco`.

Qualche differenza da conoscere: una **tupla** salvata diventa un array, e quando la rileggi è una **lista**. Una chiave numerica come `1` diventa il testo `"1"`.

<Callout kind="regola">
Se il file è danneggiato o scritto male, `json.load` solleva `json.JSONDecodeError`, che è un tipo di `ValueError`. Come per ogni lettura da file, conviene un `try` ed `except`.
</Callout>

<Say who="assistente">Il JSON non conosce date o insiemi. Per quelli, prima li converti in testo o in liste.</Say>

<Scene title="Rapporto finale">
<Recap xp={20}>
- Il JSON è un formato di testo per dati annidati: oggetti, array, stringhe, numeri, true, false e null.
- In Python dump e load lavorano con i file, dumps e loads con le stringhe.
- dict diventa oggetto, list e tuple diventano array, None diventa null; le chiavi diventano sempre testo.
- Caso chiuso: la scheda dell'attore, con ruoli e date in una lista, si salva in un unico file JSON e si rilegge identica.
</Recap>
