<Scene title="Il file che non si trova">
Elena sposta il programma in una cartella nuova e lo riavvia: `FileNotFoundError`. Il file `spese.csv` c'è, lo vede nella cartella! Eppure Python dice che non esiste.

Il guaio è il **percorso**: l'indirizzo del file nel computer. Python cerca nel posto dove si trova lui in quel momento, non dove si trova lo script.

La domanda del caso: **dove cerca Python un file quando scrivo solo il suo nome?**

<Say who="sensei">Per Python un file ha un indirizzo, come una casa. Se dai solo il nome, cerca nella via dove si trova in quel momento.</Say>

La **cartella di lavoro corrente** è la cartella da cui hai avviato il programma (quella in cui sta il terminale), che non coincide per forza con la cartella dove sta il file `.py`. Per scoprirla:

```python
from pathlib import Path
print(Path.cwd())
```

Quando scrivi `open("spese.csv")` Python cerca in quella cartella. Per questo il programma funzionava in un posto e non in un altro.

<Callout kind="trucco">
Per un file che sta **accanto allo script** usa `Path(__file__).parent / "spese.csv"`: `__file__` è il percorso dello script, `.parent` è la sua cartella. (Funziona nei file `.py`, non nella console interattiva.)
</Callout>

<Say who="assistente">Quando un file «non si trova», stampa Path.cwd(): spesso scopri subito che Python guarda altrove.</Say>
</Scene>

<Scene title="pathlib">
Il modulo `pathlib` rappresenta i percorsi come oggetti, e funziona uguale su Windows, Mac e Linux. L'operatore `/` unisce i pezzi.

```python
from pathlib import Path

cartella = Path("dati")
file = cartella / "spese.csv"
print(file)
print(file.name)
print(file.stem)
print(file.suffix)
print(file.parent)
```

<Log lines={[

  "spese",

  "dati",
]} caption="Su Windows il primo risultato sarebbe dati\\spese.csv: pathlib sceglie il separatore giusto." />

- `.name`: nome completo; `.stem`: nome senza estensione; `.suffix`: estensione, con il punto; `.parent`: la cartella che contiene il file.

<Callout kind="attenzione">
Su Windows un percorso scritto a mano come `"C:\nuovo\spese.csv"` si rompe: `\n` diventa un «a capo» e `\s` non è valido. Scrivilo come stringa **raw**, con una `r` davanti (`r"C:\nuovo\spese.csv"`), oppure usa `/` o `Path`.
</Callout>

<Scene title="Controllare e creare">
Prima di usare un file o una cartella, puoi chiedere a `Path` se ci sono.

```python
from pathlib import Path

cartella = Path("dati")
cartella.mkdir(parents=True, exist_ok=True)

file = cartella / "spese.csv"
if file.exists():
    print("Il file c'è")
else:
    print("Lo creo")
    file.write_text("data,categoria,importo\n", encoding="utf-8")
```

- `.exists()`: esiste? `.is_file()`: è un file? `.is_dir()`: è una cartella?
- `.mkdir(parents=True, exist_ok=True)` crea la cartella (e le cartelle superiori che mancano) **senza errore** se c'è già.
- `.read_text(encoding="utf-8")` e `.write_text(testo, encoding="utf-8")` leggono e scrivono un file piccolo in una sola riga.
- `Path("dati").glob("*.csv")` elenca i file `.csv` di una cartella.

<Recap xp={20}>
- Un percorso assoluto parte dalla radice del disco; uno relativo parte dalla cartella di lavoro corrente.
- pathlib.Path costruisce percorsi con / e offre name, stem, suffix, parent ed exists.
- mkdir(parents=True, exist_ok=True) crea una cartella senza errori se esiste già.
