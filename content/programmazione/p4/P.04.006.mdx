<Scene title="open e with">
Per usare un file lo si **apre** con `open`, poi lo si usa, e infine va **chiuso**. Il modo più sicuro è `with`, che lo chiude da solo anche se nel mezzo c'è un errore.

```python
with open("presenze.txt", "w", encoding="utf-8") as f:
    f.write("Anna\n")
    f.write("Marco\n")
```

- `"presenze.txt"` è il nome del file.
- `"w"` è la **modalità** (*write*, scrittura).
- `encoding="utf-8"` dice come salvare le lettere accentate: scrivilo sempre.
- `f` è il nome che diamo al file aperto. Finito il blocco `with`, il file è chiuso.

<Callout kind="attenzione">
`write` **non** va a capo da solo: devi scrivere tu `\n` (il carattere di «a capo»). Senza, «Anna» e «Marco» finiscono attaccati: `AnnaMarco`.
</Callout>

<Say who="assistente">Ricordati il with: dimenticare di chiudere un file può farlo restare incompleto.</Say>
</Scene>

<Scene title="Le modalità">
<Compare

  left={{ title: "w (scrivi)", points: ["Crea il file se non esiste", "Se esiste lo SVUOTA e riparte da zero", "Attenzione: cancella i dati vecchi"] }}

La modalità predefinita è `"r"` (*read*, lettura): se non scrivi niente, il file viene solo letto. Se il file non esiste, Python solleva `FileNotFoundError`.

```python
with open("presenze.txt", "a", encoding="utf-8") as f:
    f.write("Giulia\n")
```

<Callout kind="regola">
Vuoi **aggiungere** una riga a un file esistente? Usa `"a"`. Usare `"w"` per sbaglio è uno dei modi più rapidi per perdere i dati.
</Callout>

<Say who="sensei">Tre lettere: r legge, w riscrive da capo, a aggiunge in fondo. Impara la differenza prima di fare danni.</Say>
</Scene>

<Scene title="Leggere">
Per leggere ci sono due modi comodi.

```python
# tutto il contenuto in un'unica stringa
with open("presenze.txt", encoding="utf-8") as f:
    testo = f.read()

# una riga alla volta
with open("presenze.txt", encoding="utf-8") as f:
    for riga in f:
        print(riga.strip())
```

Quando leggi riga per riga, ogni riga **porta con sé** il carattere di a capo alla fine. Il metodo `.strip()` toglie gli spazi e gli a capo ai bordi; senza, `print` ne aggiungerebbe un altro e vedresti una riga vuota tra una e l'altra.

<Log lines={[
  "Anna",
  "Marco",
  "Giulia",
]} caption="Il risultato, dopo aver scritto due nomi e aggiunto un terzo." />

E se il file manca? Si gestisce come hai imparato:

```python
try:
    with open("presenze.txt", encoding="utf-8") as f:
        print(f.read())
except FileNotFoundError:
    print("Nessun file ancora: parto da un elenco vuoto.")
```

<Say who="assistente">All'inizio il file non esiste ancora: è normale. Un except sul FileNotFoundError ti toglie ogni preoccupazione.</Say>
</Scene>
