<Scene title="Una funzione dentro l'altra">
Una funzione può chiamarne un'altra, purché sia definita **prima che la chiamata avvenga** (non prima della definizione di chi chiama).

```python
def quadrato(n):
    return n * n

def ipotenusa(a, b):
    return (quadrato(a) + quadrato(b)) ** 0.5

print(ipotenusa(3, 4))
```

<Log lines={[
  "5.0",
]} caption="9 più 16 fa 25, e 25 elevato a 0,5 è la radice quadrata: 5.0." />

La funzione `ipotenusa` usa `quadrato` due volte. L'operatore `** 0.5` calcola la radice quadrata (elevare a 0,5 è come estrarre la radice).

Il risultato è `5.0` e non `5` perché l'elevamento a potenza con un numero decimale dà sempre un numero decimale.

<Callout kind="regola">
Non importa quale delle due funzioni è scritta per prima, ma entrambe devono essere **definite prima che la chiamata parta**: qui basta che le definizioni stiano sopra la riga `print`.
</Callout>

<Say who="assistente">Il nome `quadrato` viene cercato solo quando `ipotenusa` viene eseguita, non quando viene scritta.</Say>
</Scene>

<Scene title="L'ordine di esecuzione">
Che cosa succede, passo dopo passo, con `ipotenusa(3, 4)`?

Python lavora così: quando una funzione ne chiama un'altra, **si ferma e aspetta** che quella finisca e restituisca il risultato. Poi riprende da dove era rimasta. È come una catena di persone che si passano un compito: chi chiede resta in attesa della risposta.

Lo stesso vale per le chiamate dentro altre chiamate: Python calcola prima quelle più interne.

```python
print(quadrato(quadrato(2)))
```

Prima `quadrato(2)` dà 4, poi `quadrato(4)` dà 16, infine `print` mostra 16.

<Say who="sensei">Dal centro verso l'esterno: la parentesi più interna si risolve per prima.</Say>
</Scene>

<Scene title="Costruire in strati">
Con questa tecnica costruisci funzioni sempre più grandi senza mai riscrivere i calcoli di base.

```python
def costo_biglietti(prezzo, quanti):
    return prezzo * quanti

def costo_con_extra(prezzo, quanti, extra=2):
    return costo_biglietti(prezzo, quanti) + extra

print(costo_con_extra(5, 3))
```

]} caption="5 per 3 fa 15, più 2 di contributo: 17." />

<Scene title="Rapporto finale">
<Recap xp={20}>
- Una funzione può chiamarne un'altra: le funzioni si combinano come mattoncini.
- La funzione che chiama aspetta il risultato di quella chiamata, poi riprende.
- Con più chiamate una dentro l'altra, Python parte da quella più interna.
- Ogni funzione dovrebbe fare una cosa sola e fidarsi delle altre.
- Caso chiuso: Elena calcola la diagonale di 3 per 4 con `ipotenusa(3, 4)` e ottiene 5.0.
</Recap>
