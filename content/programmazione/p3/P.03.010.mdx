<Scene title="Le formule">
Prima di scrivere codice servono le formule. Sono fatti noti, ma controllali sempre due volte:

<Scene title="Le funzioni di conversione">
Una funzione per ogni conversione, con nome chiaro, docstring e `return`.

```python
def km_in_miglia(km):
    """Converte chilometri in miglia (1 miglio = 1,609344 km)."""
    return km / 1.609344

def celsius_in_fahrenheit(celsius):
    """Converte gradi Celsius in gradi Fahrenheit."""
    return celsius * 9 / 5 + 32

def kg_in_libbre(kg):
    """Converte chilogrammi in libbre (circa 2,20462 libbre per kg)."""
    return kg * 2.20462
```

Nessuna di queste funzioni usa `input` o `print`: calcolano e basta. Così le puoi riusare in qualsiasi programma, e provare da sole.

Una prova rapida:

```python
print(celsius_in_fahrenheit(100))
print(celsius_in_fahrenheit(0))
print(celsius_in_fahrenheit(-40))
```

<Scene title="La funzione main">
Ora serve la parte che parla con l'utente. Usa le funzioni sopra, senza ripetere i calcoli.

```python
def main():
    print("1 = km in miglia, 2 = Celsius in Fahrenheit, 3 = kg in libbre")
    scelta = input("Scelta: ")
    valore = float(input("Valore: "))
    if scelta == "1":
        print(round(km_in_miglia(valore), 2), "miglia")
    elif scelta == "2":
        print(round(celsius_in_fahrenheit(valore), 1), "gradi F")
    elif scelta == "3":
        print(round(kg_in_libbre(valore), 2), "libbre")
    else:
        print("Scelta non valida")

main()
```

<Log lines={[
  "1 = km in miglia, 2 = Celsius in Fahrenheit, 3 = kg in libbre",
  "Scelta: 2",
  "Valore: 100",
  "212.0 gradi F",

`round(numero, 2)` arrotonda a due decimali. `float(...)` trasforma il testo digitato in numero. Il valore dell'utente viene letto sempre come testo, perciò la scelta si confronta con `"1"`, `"2"`, `"3"` tra virgolette.

<Callout kind="attenzione">
Un valore non numerico, come «ciao», farebbe fermare il programma con un errore. Gestire questi casi è il tema del prossimo modulo.
</Callout>
