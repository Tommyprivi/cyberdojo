<Scene title="I nomi">
Un nome ben scelto vale più di mille commenti. Le regole di Python (raccolte nella guida di stile chiamata **PEP 8**) sono semplici:

- variabili e funzioni in **minuscolo con il trattino basso**: `prezzo_biglietto`, `calcola_media` (stile *snake_case*, «serpente»);
- il nome dice **cosa è** (per le variabili) o **cosa fa** (per le funzioni, di solito con un verbo): `squadre`, `calcola_totale`, `chiedi_numero`;
- niente nomi di una lettera, tranne dove sono d'uso comune (per esempio `i` in un ciclo);
- un nome non può iniziare con un numero né contenere spazi.

<Scene title="I commenti">
Un **commento** è una nota per chi legge: Python lo ignora. Inizia con il cancelletto `#` e arriva fino a fine riga.

```python
# il 1.2 è il margine del 20% per la gestione del torneo
totale = prezzo * quantita * 1.2
```

Un commento utile spiega il **perché**, non il **cosa**. Il codice già dice cosa fa:

```python
totale = totale + 1   # aggiungo 1 al totale     (inutile)
totale = totale + 1   # conto anche l'arbitro    (utile)
```

Un altro buon consiglio: dai un **nome** ai numeri misteriosi (i «numeri magici») invece di commentarli.

```python
MARGINE = 1.2
totale = prezzo * quantita * MARGINE
```

I nomi scritti tutto in maiuscolo sono una convenzione per le **costanti**, cioè valori che non cambiano mai. Python non lo impone, ma tutti la rispettano.

<Say who="sensei">Pochi commenti, buoni. Se il codice è chiaro, il commento serve solo per ciò che il codice non può dire.</Say>
</Scene>

<Scene title="La docstring">
Una **docstring** (in inglese *documentation string*) è il testo che descrive una funzione. Si scrive come **prima riga del corpo**, tra virgolette triple.

```python
def area_rettangolo(base, altezza):
    """Calcola l'area di un rettangolo moltiplicando base per altezza."""
    return base * altezza

help(area_rettangolo)
```

<Log lines={[
  "Help on function area_rettangolo in module __main__:",
  "",
  "area_rettangolo(base, altezza)",
  "    Calcola l'area di un rettangolo moltiplicando base per altezza.",
]} caption="help legge la docstring e la mostra." />

A differenza di un commento con `#`, la docstring **non viene ignorata**: Python la conserva, e la puoi leggere con `help(nome)` oppure con `nome.__doc__`.

Una buona docstring dice in una frase **cosa fa** la funzione, e se serve cosa riceve e cosa restituisce.

<Callout kind="trucco">
Anche le funzioni che usi tutti i giorni hanno una docstring: prova `help(print)` e leggi come funziona.
</Callout>

<Say who="assistente">La docstring è il cartellino sulla scatola: chi apre la scatola sa cosa contiene senza smontarla.</Say>
</Scene>
