<Scene title="Che cos'è un modulo">
Un **modulo** è un file Python che contiene funzioni (e altro) pronte da usare in altri programmi. Per usarlo si scrive `import` all'inizio del file.

Python viene fornito con tanti moduli già inclusi, che formano la **libreria standard**. Alcuni esempi:

- `math`: funzioni matematiche (radice quadrata, arrotondamenti, il valore di pi greco);
- `random`: numeri casuali;
- `datetime`: date e orari.

```python
import random

dado = random.randint(1, 6)
print("È uscito", dado)
```

`random.randint(1, 6)` restituisce un numero intero a caso **tra 1 e 6, estremi compresi**. Ad ogni esecuzione può uscire un numero diverso.

<Callout kind="regola">
Dopo `import modulo`, per usare una funzione scrivi il **nome del modulo**, un punto e il nome della funzione: `random.randint(...)`. Senza il prefisso, Python non la trova.
</Callout>

<Say who="assistente">Il punto significa «dentro». `random.randint` si legge: la funzione randint, che sta dentro random.</Say>
</Scene>

<Scene title="Tre modi di importare">
Ci sono tre forme, e ognuna ha il suo uso.

```python
import math
print(math.sqrt(16))        # 4.0

from math import sqrt
print(sqrt(16))             # 4.0

import math as m
print(m.sqrt(16))           # 4.0
```

<Compare
  caption="Tre forme dell'importazione."
  left={{ title: "import modulo", points: ["Porta tutto il modulo", "Si scrive math.sqrt", "Chiaro da dove viene la funzione"] }}
  right={{ title: "from modulo import nome", points: ["Porta solo ciò che nomini", "Si scrive sqrt, senza prefisso", "Più breve, ma meno chiaro"] }}
/>

La terza forma, `import math as m`, dà al modulo un **nome più corto** (un *alias*): utile con nomi lunghi.

Altre due cose utili del modulo `math`: `math.pi` vale circa 3,14159 e `math.floor(3.7)` dà 3 (arrotonda per difetto).

<Callout kind="trucco">
Per iniziare usa `import modulo`: quando leggi `math.sqrt` sai subito da dove arriva la funzione. Le altre forme servono quando il codice diventa lungo.
</Callout>

<Say who="sensei">Gli import si scrivono in cima al file, tutti insieme. Chi legge sa subito di cosa hai bisogno.</Say>
</Scene>

<Scene title="Il tuo modulo">
Ogni file Python che scrivi può diventare un modulo. Se nella cartella hai `utili.py` con questo contenuto:

```python
def saluta(nome):
    return "Ciao, " + nome + "!"
```

in un altro file della **stessa cartella** puoi scrivere:

```python
import utili

print(utili.saluta("Elena"))
```

<Log lines={[
  "Ciao, Elena!",
]} caption="Il file utili.py diventa il modulo utili." />

Il nome del modulo è il nome del file **senza** `.py`.

<Callout kind="attenzione">
Non dare ai tuoi file il nome di un modulo di Python: un file chiamato `random.py` o `math.py` nella tua cartella prende il posto di quello vero, e i programmi smettono di funzionare in modo strano.
</Callout>

<Recap xp={20}>
- Un modulo è un file Python con funzioni pronte da usare.
- La libreria standard è inclusa in Python: math, random, datetime e molti altri.
- `import modulo` richiede il prefisso, `from modulo import nome` no, `import modulo as alias` accorcia il nome.
- Un tuo file `.py` nella stessa cartella è un modulo importabile con il suo nome senza `.py`.
- Caso chiuso: Elena usa `random.randint(1, 6)` per tirare il dado.
