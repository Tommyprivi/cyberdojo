<Scene title="I parametri: i dati che entrano">
I **parametri** sono nomi che scrivi tra le parentesi della definizione. Sono come variabili che ricevono i dati al momento della chiamata.

```python
def saluta(nome):
    print("Ciao,", nome)

saluta("Elena")
saluta("Marco")
```

<Log lines={[
  "Ciao, Elena",
  "Ciao, Marco",
]} caption="Stessa funzione, dati diversi." />

I valori che scrivi nella chiamata (`"Elena"`, `"Marco"`) si chiamano **argomenti**. Python li assegna ai parametri **in ordine**: il primo argomento al primo parametro, il secondo al secondo.

<Callout kind="regola">
**Parametro** è il nome nella definizione, **argomento** è il valore nella chiamata. Si dice anche solo «parametri» per tutti e due: la cosa importante è l'ordine.
</Callout>

<Say who="assistente">Il parametro è un segnaposto: dice «qui arriverà un dato». L'argomento è il dato vero.</Say>
</Scene>

<Scene title="return: il risultato che esce">
Per far uscire un risultato dalla funzione si usa `return`.

```python
def area_rettangolo(base, altezza):
    return base * altezza

area = area_rettangolo(5, 3)
print(area)
```

<Log lines={[
  "15",
]} caption="La funzione restituisce 15, che finisce nella variabile area." />

Quando Python incontra `return`, **la funzione finisce subito** e il valore torna a chi l'ha chiamata. Per questo ciò che è scritto dopo `return` non viene mai eseguito.

/>

<Say who="sensei">Ora puoi usare il risultato: metterlo in una variabile, sommarlo, passarlo a un'altra funzione.</Say>

<Scene title="return e print non sono la stessa cosa">
È l'errore più comune. `print` **mostra** un valore sullo schermo. `return` **consegna** un valore al programma.

```python
def doppio_con_print(n):
    print(n * 2)

def doppio_con_return(n):
    return n * 2

a = doppio_con_print(4)
b = doppio_con_return(4)
print(a)
print(b)
```

<Log lines={[
  "8",
  "None",
  "8",
]} caption="La prima riga viene dalla funzione, poi a vale None, poi b vale 8." />

La funzione con `print` ha mostrato 8, ma non l'ha restituito: `a` vale `None`, che in Python significa «niente». La funzione con `return` ha consegnato 8 e `b` lo contiene.

<Callout kind="trucco">
Domanda da farti: «mi serve **vedere** il risultato o **usarlo** dopo?». Se lo devi usare, serve `return`. Un print finale puoi sempre farlo fuori dalla funzione.
</Callout>

<Say who="assistente">Una funzione senza return restituisce comunque qualcosa: `None`. Così sai che è vuoto.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- I parametri sono i nomi tra parentesi nella definizione e ricevono i dati.
- Gli argomenti sono i valori nella chiamata e vanno in ordine ai parametri.
- `return` restituisce un valore e termina subito la funzione.
- `print` mostra un valore, non lo restituisce: una funzione senza return dà `None`.
- Caso chiuso: con `area_rettangolo(base, altezza)` Elena calcola l'area di qualsiasi rettangolo.
</Recap>
