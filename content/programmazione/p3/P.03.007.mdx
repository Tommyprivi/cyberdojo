Elena scrive il programma che calcola la media dei voti dei suoi tre compagni di squadra a un corso di primo soccorso. Funziona, ma è una lista unica di righe: input, calcolo, giudizio, stampa, tutto mischiato. Quando vuole cambiare il giudizio, deve rileggere tutto per capire dove metterci le mani.

La domanda del caso: **come si riordina un programma lungo, così che ogni parte sia facile da trovare e da cambiare?**

<Scene title="Un compito, una funzione">
La tecnica è questa: guarda che cosa fa il programma, scrivi la lista dei compiti, e fai una funzione per ciascuno.

I compiti del programma di Elena sono tre: chiedere un voto, calcolare la media, dare un giudizio. Una buona funzione fa **una cosa sola** e ha un nome che la descrive. In più, separa il **calcolo** dalla **stampa**: una funzione che calcola e restituisce si può riusare ovunque, una che stampa sì o no.

<Callout kind="regola">
Tieni separati **calcolare** e **mostrare**. Le funzioni che calcolano usano `return`; solo la parte finale del programma usa `print`.
</Callout>

<Say who="assistente">Se a volte mi chiedo se una funzione fa troppo, provo a descriverla in una frase. Se serve un «e», probabilmente sono due funzioni.</Say>
</Scene>

<Scene title="Le funzioni piccole">
Ecco le tre funzioni di Elena:

```python
def chiedi_numero(domanda):
    return float(input(domanda))

def media(a, b, c):
    return (a + b + c) / 3

def giudizio(voto):
    if voto >= 6:
        return "sufficiente"
    return "insufficiente"
```

Ognuna fa una cosa:
- `chiedi_numero` legge un valore dall'utente e lo trasforma in numero (`float` converte il testo in numero decimale).
- `media` calcola la media di tre numeri: nessuna stampa.
- `giudizio` restituisce una parola in base al voto.

Nota che `giudizio` non ha bisogno di `else`: se la condizione è vera, `return` chiude la funzione; altrimenti si passa alla riga dopo.

<Say who="sensei">Funzioni brevi, nomi chiari. Se riesci a leggerle a voce alta come una frase, sei sulla strada giusta.</Say>
</Scene>

<Scene title="La funzione main">
Resta da coordinare tutto. Per convenzione si scrive una funzione chiamata `main` (in inglese «principale») che chiama le altre nell'ordine giusto.

```python
def main():
    v1 = chiedi_numero("Voto 1: ")
    v2 = chiedi_numero("Voto 2: ")
    v3 = chiedi_numero("Voto 3: ")
    m = media(v1, v2, v3)
    print("Media:", round(m, 1), "-", giudizio(m))

main()
```

<Log lines={[
  "Voto 1: 6",
  "Voto 2: 7",
  "Voto 3: 8",
  "Media: 7.0 - sufficiente",
]} caption="Esempio di esecuzione con i voti 6, 7 e 8." />

L'ultima riga, `main()`, fa partire tutto. Leggendo solo `main` capisci cosa fa il programma, senza guardare i dettagli.

<Callout kind="curiosita">
Nei file Python si trova spesso la riga `if __name__ == "__main__":` seguita da `main()`. Significa «esegui main solo se questo file è stato lanciato direttamente, non se un altro programma lo sta importando». Lo capirai meglio con i moduli, tra due lezioni.
</Callout>

<Say who="assistente">`main` è la scaletta: elenca i passi, senza spiegarli. I dettagli stanno nelle altre funzioni.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- Per riordinare un programma elenca i compiti e fai una funzione per ciascuno.
- Una buona funzione fa una cosa sola e ha un nome che la descrive.
- Calcolo e stampa si tengono separati: il calcolo restituisce con return.
- La funzione `main` chiama le altre nell'ordine giusto e si avvia con `main()`.
- Caso chiuso: Elena divide il programma dei voti in `chiedi_numero`, `media`, `giudizio` e `main`.
</Recap>
