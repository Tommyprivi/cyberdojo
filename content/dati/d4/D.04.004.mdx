<Scene title="Il DataFrame">
Un **DataFrame** è la tabella di pandas: righe numerate a sinistra (l'**indice**) e colonne con un nome. Il modo più semplice per crearlo è da un **dizionario**: ogni chiave è il nome di una colonna, ogni lista contiene i suoi valori.

```python
import pandas as pd

ordini = pd.DataFrame({
    "cliente": ["Anna", "Bruno", "Carla", "Dario", "Elisa", "Anna"],
    "citta": ["Roma", "Milano", "Roma", "Torino", "Milano", "Roma"],
    "prodotto": ["casco", "luci", "casco", "borraccia", "luci", "luci"],
    "quantita": [1, 2, 1, 4, 3, 3],
    "importo": [40.0, 20.0, 40.0, 20.0, 30.0, 30.0],
})
print(ordini)
```

```text
   cliente   citta   prodotto  quantita  importo
0     Anna    Roma      casco         1     40.0
1    Bruno  Milano       luci         2     20.0
2    Carla    Roma      casco         1     40.0
3    Dario  Torino  borraccia         4     20.0
4    Elisa  Milano       luci         3     30.0
5     Anna    Roma       luci         3     30.0
```

Le liste devono avere **tutte la stessa lunghezza**, altrimenti pandas dà un `ValueError`. Non scrivere i dati a mano nei lavori veri: di solito si leggono da un file, come vedremo nella prossima lezione.

<Scene title="La Series: una colonna sola">
Quando estrai **una colonna** con le parentesi quadre ottieni una **Series**: una fila di valori con indice e nome.

```python
print(ordini["importo"])
```

```text
0    40.0
1    20.0
2    40.0
3    20.0
4    30.0
5    30.0
Name: importo, dtype: float64
```

L'ultima riga dice due cose: il **nome** della colonna (`importo`) e il **tipo** dei valori (`float64`, numeri con la virgola). Se invece scrivi `ordini[["importo"]]`, con le parentesi doppie, ottieni di nuovo una tabella con una sola colonna.

Una Series si può creare anche da sola, e conosce già i trucchi di NumPy, perché dentro c'è un array:

```python
importi = pd.Series([40.0, 20.0, 40.0], name="importo")
print(importi.mean(), importi.max())
```

```text
33.333333333333336 40.0
```

<Scene title="Guardare la tabella">
Prima di ogni analisi si fanno sempre le stesse domande. Ognuna ha il suo comando:

```python
print(ordini.head(2))
print(ordini.shape)
print(ordini.columns)
```

```text
   cliente   citta  prodotto  quantita  importo
0     Anna    Roma     casco         1     40.0
1    Bruno  Milano      luci         2     20.0
(6, 5)
Index(['cliente', 'citta', 'prodotto', 'quantita', 'importo'], dtype='object')
```

- `head(n)` mostra le **prime n righe** (di default 5): per tabelle grandi è l'unico modo ragionevole di guardarle;
- `shape` dà (righe, colonne): qui 6 righe e 5 colonne;
- `columns` elenca i nomi delle colonne.

Per il **tipo** di ogni colonna si usa `dtypes`:

```python
print(ordini.dtypes)
```

```text
cliente      object
citta        object
prodotto     object
quantita      int64
importo     float64
dtype: object
```

`object` è il tipo del testo (nelle versioni più recenti di pandas puoi vedere `str`: è la stessa cosa), `int64` i numeri interi, `float64` quelli con la virgola.

<Scene title="info e describe">
`info()` è la radiografia della tabella: righe, colonne, tipi e **quante celle sono piene** in ciascuna.

```python
ordini.info()
```

```text
<class 'pandas.core.frame.DataFrame'>
RangeIndex: 6 entries, 0 to 5
Data columns (total 5 columns):
 #   Column    Non-Null Count  Dtype  
---  ------    --------------  -----  
 0   cliente   6 non-null      object 
 1   citta     6 non-null      object 
 2   prodotto  6 non-null      object 
 3   quantita  6 non-null      int64  
 4   importo   6 non-null      float64
dtypes: float64(1), int64(1), object(3)
```

Dopo l'ultima riga ne compare un'altra, `memory usage`, con la memoria occupata: cambia da computer a computer e per ora non ti serve. Quello che conta è `Non-Null Count`: se una colonna ha meno di 6 celle piene, ci sono **valori mancanti**.

`describe()` calcola le statistiche principali delle colonne numeriche. Qui lo chiediamo solo per `importo`:

```python
print(ordini["importo"].describe())
```

```text
count     6.000000
mean     30.000000
std       8.944272
min      20.000000
25%      22.500000
50%      30.000000
75%      37.500000
max      40.000000
Name: importo, dtype: float64
```

Conta 6 valori, media 30, deviazione standard 8,94 (pandas divide per n-1, come visto con `ddof=1`), minimo 20, massimo 40. Il 25% e il 75% sono i **quartili**: sotto il 25% c'è un quarto dei valori. Il 50% è la **mediana**.
