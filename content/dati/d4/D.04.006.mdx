<Scene title="Scegliere le colonne">
Una colonna si sceglie con il suo nome tra parentesi quadre. Più colonne: una **lista** di nomi, quindi due coppie di parentesi.

```python
print(ordini["citta"].head(2))
print(ordini[["cliente", "importo"]])
```

```text
0      Roma
1    Milano
Name: citta, dtype: object
   cliente  importo
0     Anna     40.0
1    Bruno     20.0
2    Carla     40.0
3    Dario     20.0
4    Elisa     30.0
5     Anna     30.0
```

Con una coppia di parentesi ottieni una **Series**. Con la lista, cioè due coppie, ottieni un **DataFrame**.

</Callout>

<Scene title="loc e iloc: etichette e posizioni">
Per scegliere **righe e colonne insieme** servono `loc` e `iloc`. La differenza è una sola:

- **`loc`** usa le **etichette**: il numero dell'indice e il nome della colonna;
- **`iloc`** usa le **posizioni** (come in una lista): 0 è la prima riga, 0 la prima colonna.

```python
print(ordini.loc[2, "cliente"])
print(ordini.iloc[0, 1])
print(ordini.loc[1:3, ["cliente", "importo"]])
print(ordini.iloc[1:3, [0, 4]])
```

```text
Carla
Roma
   cliente  importo
1    Bruno     20.0
2    Carla     40.0
3    Dario     20.0
   cliente  importo
1    Bruno     20.0
2    Carla     40.0
```

`loc[1:3]` prende le righe 1, 2 **e 3**: con le etichette l'estremo è incluso. `iloc[1:3]` prende le posizioni 1 e 2: come nelle liste, l'estremo è escluso. `iloc[0, 1]` è la riga 0 e la colonna in posizione 1, cioè `citta`.

<Callout kind="regola">
Etichetta o posizione? Se ti viene da dire «la riga numero 3», domandati: numero dell'indice o terza riga dall'alto? Sono due cose diverse, e dopo un filtro diventano davvero diverse.
</Callout>

<Say who="sensei">loc cerca per nome, iloc per posto. Come il biglietto del cinema: la fila C, oppure il terzo da sinistra.</Say>
</Scene>

<Scene title="La maschera booleana">
Per filtrare si scrive una **condizione** sulla colonna. Il risultato è una **maschera**: una Series di vero e falso, una per riga.

```python
print(ordini["importo"] > 25)
```

```text
0     True
1    False
2     True
3    False
4     True
5     True
Name: importo, dtype: bool
```

Se metti la maschera tra parentesi quadre del DataFrame, tieni **solo le righe vere**:

```python
filtrato = ordini[ordini["importo"] > 25]
print(filtrato)
```

```text
   cliente   citta  prodotto  quantita  importo
0     Anna    Roma     casco         1     40.0
2    Carla    Roma     casco         1     40.0
4    Elisa  Milano      luci         3     30.0
5     Anna    Roma      luci         3     30.0
```

Guarda l'indice: restano 0, 2, 4, 5. **I numeri dell'indice non si rinumerano.** Ecco la trappola di prima:

```python
print(filtrato.loc[2, "cliente"])
print(filtrato.iloc[2, 0])
```

```text
Carla
Elisa
```

`loc[2]` cerca l'etichetta 2 (Carla). `iloc[2]` prende la terza riga dall'alto, che ha etichetta 4 (Elisa).

<Say who="assistente">Dopo un filtro l'indice ha dei buchi: è normale. Se li vuoi togliere, aggiungi .reset_index(drop=True).</Say>
</Scene>

<Scene title="Più condizioni insieme">
Per il caso di Giulia servono due condizioni: **Roma e sopra i 25**. Si combinano con `&` (e), `|` (oppure), `~` (non). **Ogni condizione va tra parentesi.**

```python
roma = ordini[(ordini["citta"] == "Roma") & (ordini["importo"] > 25)]
print(roma)
```

```text
   cliente  citta  prodotto  quantita  importo
0     Anna   Roma     casco         1     40.0
2    Carla   Roma     casco         1     40.0
5     Anna   Roma      luci         3     30.0
```

Tre righe: la risposta alla domanda di Giulia. Se vuoi anche scegliere la colonna, usa `loc` con la maschera e il nome:

```python
print(ordini.loc[ordini["citta"] == "Roma", "importo"])
```

```text
0    40.0
2    40.0
5    30.0
Name: importo, dtype: float64
```

Per «una di queste città» c'è `isin`, molto più comodo di tanti `|`:

```python
print(ordini[ordini["citta"].isin(["Roma", "Torino"])])
```

```text
   cliente   citta   prodotto  quantita  importo
0     Anna    Roma      casco         1     40.0
2    Carla    Roma      casco         1     40.0
3    Dario  Torino  borraccia         4     20.0
5     Anna    Roma       luci         3     30.0
```

<Callout kind="attenzione">
Errori tipici: usare `and` al posto di `&` dà `ValueError: The truth value of a Series is ambiguous`; dimenticare le parentesi fa applicare `&` prima del confronto e dà un errore. E ricorda `==` per confrontare: un solo `=` assegna.
</Callout>

<Say who="sensei">Le parentesi non sono estetica. Senza di esse Python legge un'altra frase. Mettile sempre.</Say>
</Scene>

<Scene title="query: la stessa cosa, più leggibile">
Il metodo `query` scrive la condizione come una frase, in un testo. Il risultato è identico:

```python
soglia = 25
print(ordini.query("citta == 'Roma' and importo > @soglia"))
```

```text
   cliente  citta  prodotto  quantita  importo
0     Anna   Roma     casco         1     40.0
2    Carla   Roma     casco         1     40.0
5     Anna   Roma      luci         3     30.0
```

Dentro `query` si scrivono i nomi delle colonne senza `ordini[...]`, si usa `and` e `or` (qui vanno bene!), e per usare una variabile del notebook le si mette davanti la chiocciola `@`. Il testo da confrontare sta tra apici dentro il testo della query, per questo `'Roma'` ha gli apici singoli e la query esterna le virgolette.

Quando scegliere? `query` è più leggibile per condizioni semplici. La maschera con `&` è più flessibile e funziona con ogni colonna, anche con nomi con gli spazi.

<Scene title="Rapporto finale">
<Recap xp={20}>
- `df["col"]` è una Series, `df[["a", "b"]]` un DataFrame. `loc` usa le etichette (estremo incluso), `iloc` le posizioni (estremo escluso).
- Filtrare: `df[df["importo"] > 25]`; condizioni combinate con `&`, `|`, `~`, ciascuna tra parentesi; `isin` per più valori.
- Dopo un filtro l'indice non si rinumera. `query("citta == 'Roma' and importo > @soglia")` è la forma scritta come frase.
</Recap>
