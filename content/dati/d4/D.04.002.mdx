<Scene title="Variabili: un nome per un valore">
Una **variabile** è un'etichetta attaccata a un valore. Si crea con `=`:

```python
cliente = "Anna"
importo = 40.5
quantita = 3
ordine_ok = True
print(type(quantita), type(importo), type(cliente), type(ordine_ok))
```

```text
<class 'int'> <class 'float'> <class 'str'> <class 'bool'>
```

I quattro tipi che userai di continuo: **int** (numero intero), **float** (numero con la virgola, che in Python è un punto), **str** (testo, tra virgolette) e **bool** (vero o falso: `True` o `False`).

<Callout kind="attenzione">
Un solo `=` significa «metti questo valore nella variabile». Per chiedere «sono uguali?» si usa `==`. Scambiarli è l'errore più comune dei principianti.
</Callout>

Le operazioni: `+`, `-`, `*`, `/`. La divisione dà sempre un numero con la virgola: `10 / 4` fa `2.5`. Per la divisione senza resto si usa `//` (`10 // 4` fa `2`) e per il resto `%` (`10 % 4` fa `2`).

<Scene title="Liste: tanti valori in fila">
Una **lista** tiene più valori in un ordine preciso. Si scrive tra parentesi quadre.

```python
clienti = ["Anna", "Bruno", "Carla"]
print(clienti[0])
print(clienti[-1])
clienti.append("Dario")
print(len(clienti))
print(clienti[1:3])
```

```text
Anna
Carla
4
['Bruno', 'Carla']
```

Tre regole da ricordare:

- l'indice parte da **0**: il primo è `clienti[0]`;
- `-1` è l'ultimo elemento;
- `clienti[1:3]` prende dal 1 **fino al 3 escluso**: quindi gli elementi di indice 1 e 2.

Per ripetere un'azione su ogni elemento si usa `for`. Nota i due punti e i quattro spazi a sinistra: sono obbligatori.

```python
importi = [40.0, 20.0, 40.0]
totale = 0
for importo in importi:
    totale = totale + importo
print(totale)
```

```text
100.0
```

Ecco il totale di Giulia. Fra poco lo farai con una sola parola.

<Scene title="Dizionari: valori con un'etichetta">
Un **dizionario** tiene coppie «etichetta: valore». L'etichetta si chiama **chiave**. Si scrive tra parentesi graffe.

```python
ordine = {"cliente": "Anna", "citta": "Roma", "importo": 40.0}
print(ordine["citta"])
ordine["importo"] = 45.0
print(ordine)
print(ordine.get("sconto", 0))
```

```text
Roma
{'cliente': 'Anna', 'citta': 'Roma', 'importo': 45.0}
0
```

Se chiedi una chiave che non esiste con le parentesi quadre, ottieni un errore: `ordine["sconto"]` dà `KeyError: 'sconto'`. Con `.get("sconto", 0)` invece ricevi un valore di riserva, qui `0`.

Una lista di dizionari è già quasi una tabella: ogni dizionario è una riga, ogni chiave è una colonna.

```python
ordini = [
    {"cliente": "Anna", "importo": 40.0},
    {"cliente": "Bruno", "importo": 20.0},
]
print(ordini[1]["cliente"])
```

```text
Bruno
```

Prima l'elemento 1 della lista (il secondo dizionario), poi la chiave `"cliente"`. Nel modulo successivo trasformeremo proprio una struttura così in un **DataFrame** di pandas.

<Scene title="Funzioni: un calcolo con un nome">
Una **funzione** è un calcolo a cui dai un nome, per rifarlo senza riscriverlo. Si definisce con `def`, e con `return` restituisce il risultato.

```python
def sconto(prezzo, percentuale=10):
    return prezzo - prezzo * percentuale / 100

print(sconto(50))
print(sconto(80, 25))
```

```text
45.0
60.0
```

`prezzo` e `percentuale` sono i **parametri**. Quando scrivi `percentuale=10` dai un valore di riserva: se chiami `sconto(50)` lo sconto è del 10 per cento. Con `sconto(80, 25)` lo cambi.

<Callout kind="attenzione">
Senza `return` la funzione fa i conti ma non restituisce niente. Python ti consegna `None`, cioè «nessun valore». Se vedi `None` al posto di un numero, controlla se hai dimenticato `return`.
</Callout>
