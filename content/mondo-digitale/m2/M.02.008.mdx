<Scene title="La fattura che non si apre">
Il nonno Aldo riceve un messaggio: «Scarica la tua fattura». Scarica il file, fa doppio click, e non succede niente di strano. Poi il computer comincia a rallentare e compaiono finestre che non conosce.

Marta guarda il file: si chiama **fattura.pdf.exe**. Non era un documento: era un **programma**.

La domanda del caso: **come si capisce se un file scaricato è sicuro da aprire?**

<Say who="sensei">Scaricare è facile. Il difficile è decidere che cosa aprire e che cosa buttare.</Say>

<Scene title="Che cos'è un download">
**Scaricare** (in inglese *download*) vuol dire copiare un file da un server al tuo dispositivo. Il browser lo mette di solito nella cartella **Download** (o **Scaricati**). Dal menu, voce **Download** (in Chrome ed Edge anche con Ctrl + J), vedi la lista dei file scaricati.

Scaricare un file non lo apre né lo esegue: il rischio comincia quando **lo apri**.

<Scene title="L'estensione dice che cosa è">
Il nome di un file finisce con un **punto** e poche lettere: l'**estensione**. Dice di che tipo è il file.

- Documenti e immagini: `.pdf`, `.docx`, `.jpg`, `.png`, `.mp3`. Di solito sono dati da leggere.
- **Programmi** che si eseguono: `.exe` e `.msi` (Windows), `.apk` (Android), `.dmg` (Mac). Se li apri, **eseguono istruzioni** sul tuo dispositivo.
- Archivi compressi: `.zip`, che contengono altri file e vanno aperti con cautela.

<Callout kind="attenzione">
Su Windows le estensioni possono essere **nascoste** di default: il file «fattura.pdf.exe» si vedrebbe solo come «fattura.pdf», ma è un programma. Nelle opzioni di Esplora file si può attivare la visualizzazione delle estensioni dei file. Conta solo l'**ultima** estensione.
</Callout>

<Scene title="Controlli prima di aprire">
Prima di aprire un file scaricato, fai queste domande:

1. **L'ho cercato io, o mi è arrivato?** Un file non richiesto, ricevuto da sconosciuti, è sospetto.
2. **Da dove viene?** Preferisci il sito ufficiale o gli store ufficiali (Microsoft Store, App Store, Google Play).
3. **Il nome e l'estensione sono giusti?** Una fattura dovrebbe essere un `.pdf`, non un programma.
4. **Chi me l'ha mandato è davvero chi dice?** Se un amico ti manda un file che non ti aspetti, chiedigli conferma con un altro mezzo.

Altri accorgimenti:

- Diffida di versioni «gratis» di programmi o giochi a pagamento: sono spesso un modo per far installare virus.
- Tieni attivo l'**antivirus**: su Windows c'è già Microsoft Defender, incluso nel sistema.
- Se un documento Office ti chiede di «abilitare le macro» o i contenuti, **non farlo** se non sei sicuro: è un modo noto per far partire istruzioni nascoste.

<Callout kind="regola">
Nel dubbio, **non aprire**. Cancella il file o chiedi a una persona di fiducia. Un file non aperto non può fare danni.
</Callout>

<Scene title="Rapporto finale">
<Recap xp={20}>
- Scaricare vuol dire copiare un file sul tuo dispositivo, di solito nella cartella Download.
- Il rischio comincia quando apri il file; conta l'ultima estensione del nome.
- File come .exe, .msi e .apk sono programmi: si installano solo da fonti di cui ti fidi.
- Controlla la fonte, l'estensione e se il file te lo aspettavi; nel dubbio, non aprire.
- Caso chiuso: «fattura.pdf.exe» era un programma travestito da documento.
</Recap>
