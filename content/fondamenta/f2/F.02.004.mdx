<Scene title="Mai sull'originale">
Il collega del SOC è chiaro:

La domanda del caso: **come si prepara uno spazio di lavoro sicuro, e come si maneggiano i file senza fare danni?**

<Say who="sensei">Si lavora su una copia. L'originale resta dov'è. Questa è la regola numero uno di chi fa indagini.</Say>

<Scene title="mkdir e touch: creare">
- **mkdir** (make directory) crea una cartella
- **touch** crea un **file vuoto** (se il file esiste già, aggiorna solo la data di modifica, senza cambiare il contenuto)

<Log lines={[
  "studente@lab:~$ mkdir prova",
  "studente@lab:~$ cd prova",
  "studente@lab:~/prova$ touch note.txt",
  "studente@lab:~/prova$ ls",
  "note.txt",
]} caption="Una cartella di prova, e dentro un file vuoto." />

<Callout kind="regola">
Prima di fare **qualsiasi** cosa che modifica file: `pwd`. Controlla di essere nella cartella di prova, non altrove.
</Callout>

<Callout kind="trucco">
Con `mkdir -p prova/uno/due` crei in un colpo solo tutta la catena di cartelle. Senza `-p` il comando fallisce se «prova/uno» non esiste ancora.
</Callout>

<Say who="assistente">Se mkdir risponde «File exists», la cartella c'è già. Nessun danno: usa quella.</Say>
</Scene>

{/* screen */}

<Scene title="cp: copiare">
**cp** (copy) duplica un file. Il formato è: cp **da dove** **dove**. L'originale resta al suo posto.

<Log lines={[
  "studente@lab:~/prova$ cp note.txt copia.txt",
  "studente@lab:~/prova$ ls",
  "copia.txt  note.txt",
]} />

Per copiare una **cartella** con tutto quello che contiene serve l'opzione **-r** (ricorsivo):

<Log lines={[
  "studente@lab:~$ cp -r prova prova2",
]} caption="Senza -r, cp si rifiuta di copiare una cartella." />

<Callout kind="attenzione">
Se il file di destinazione esiste già, di norma `cp` lo **sovrascrive senza chiedere**. Controlla con `ls` prima di scegliere il nome della copia.
</Callout>

<Say who="sensei">Da dove, poi dove. Se inverti l'ordine, la copia vecchia schiaccia quella nuova.</Say>
</Scene>

{/* screen */}

<Scene title="mv: spostare e rinominare">
**mv** (move) fa due lavori con lo stesso comando:

- se la destinazione è un **nuovo nome**, **rinomina**
- se la destinazione è una **cartella**, **sposta**

<Log lines={[
  "studente@lab:~/prova$ mv copia.txt appunti.txt",
  "studente@lab:~/prova$ mkdir archivio",
  "studente@lab:~/prova$ mv appunti.txt archivio/",
  "studente@lab:~/prova$ ls",
  "archivio  note.txt",
  "studente@lab:~/prova$ ls archivio",
  "appunti.txt",
]} caption="Prima rinomino, poi sposto nella cartella archivio." />

<Compare
  caption="Copiare e spostare: che cosa resta nel vecchio posto."
  left={{ title: "cp (copia)", points: ["L'originale resta dov'è", "Ora i file sono due", "Per le cartelle serve -r"] }}
  right={{ title: "mv (sposta)", points: ["L'originale lascia il vecchio posto", "Il file resta uno solo", "Con un nuovo nome, rinomina"] }}
/>

<Callout kind="curiosita">
In Linux **rinominare e spostare sono la stessa cosa**: cambia solo il «percorso» del file. Per questo c'è un solo comando.
</Callout>

Vuoi vederlo fare da un'altra voce? Pochi minuti:

<Video />

<Say who="assistente">Con mv l'originale sparisce dal vecchio posto. Se vuoi tenerlo, usa cp.</Say>
</Scene>

<Scene title="rm: con cautela">
**rm** (remove) cancella i file. Attenzione: su Linux **non esiste il cestino**. Quello che cancelli è perso.

<Log lines={[
  "studente@lab:~/prova$ rm -i note.txt",
  "rm: remove regular empty file 'note.txt'? y",
  "studente@lab:~/prova$ ls",
  "archivio",
]} caption="L'opzione -i chiede conferma prima di cancellare: rispondi y per sì, n per no." />

Tre abitudini per non farsi male:

- `pwd` e `ls` prima di cancellare
- `rm -i` finché stai imparando
- niente `-f` (forza, senza chiedere) né `-r` (cancella le cartelle) finché non sai che cosa colpiscono

<Callout kind="attenzione">
In questo corso cancelli **solo** dentro la tua cartella di prova.
</Callout>

<Say who="sensei">Nel dubbio non cancellare. Si può sempre cancellare domani, ma non si recupera ciò che hai tolto oggi.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- mkdir crea cartelle, touch crea file vuoti, cp copia (con -r anche le cartelle), mv sposta o rinomina.
- rm cancella per sempre, senza cestino: usa rm -i e controlla con pwd e ls prima.
- Caso chiuso: si lavora sulle copie, mai sull'originale, dentro una cartella di prova.
</Recap>
