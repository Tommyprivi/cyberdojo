<Scene title="Il registro degli accessi">
Nella tua cartella di lavoro c'è un file: **registro.log**. È il registro degli accessi al computer di laboratorio. Il collega del SOC chiede:

«Quanti eventi ci sono? Quali sono gli ultimi? C'è qualcosa di strano?»

Per ora il file è chiuso: non hai un programma con le icone per aprirlo. Ma sai già muoverti, e ora impari a **leggere**.

La domanda del caso: **come si legge un file di testo dal terminale, anche quando è lunghissimo?**

<Say who="sensei">Un registro vero ha migliaia di righe. Leggerlo tutto è impossibile: si guardano l'inizio, la fine e i numeri.</Say>
</Scene>

{/* screen */}

<Scene title="cat: tutto subito">
**cat** stampa **tutto** il contenuto di un file sullo schermo. Va bene per i file piccoli.

<Log lines={[
  "studente@lab:~/indagine$ cat registro.log",
  "09:01 login ok utente=anna",
  "09:05 login ok utente=marco",
  "09:12 login fallito utente=admin",
  "09:12 login fallito utente=admin",
  "09:13 login fallito utente=admin",
  "09:20 logout utente=anna",
]} caption="Un registro fittizio di sei righe. Un file vero sarebbe molto più lungo." />

<Callout kind="curiosita">
Il nome viene da «concatenate» (unire): cat serve anche a unire più file. Ma qui lo usi solo per leggere, e **non modifica mai** il file.
</Callout>

<Say who="assistente">Guarda le righe 3, 4 e 5: tre accessi falliti di fila allo stesso utente. Tienilo a mente, ci torneremo.</Say>
</Scene>

{/* screen */}

<Scene title="less: una pagina alla volta">
Se il file è lungo, cat te lo fa scorrere davanti in un lampo. Per questo c'è **less**: mostra il file **una pagina alla volta**.

<Log lines={[
  "studente@lab:~/indagine$ less registro.log",
]} caption="less apre il file e resta aperto, finché non lo chiudi." />

I tasti di less:

- **Spazio**: pagina successiva
- **b**: pagina precedente
- **/parola** e Invio: cerca una parola
- **q**: esci, e torni al prompt

<Callout kind="attenzione">
Dentro less il prompt non c'è: i comandi che scrivi non partono. Se ti sembra bloccato, premi **q**.
</Callout>

<Say who="sensei">less si chiude con q. Impara questo tasto: ti salva ogni volta che ti senti in trappola.</Say>
</Scene>

{/* screen */}

<Scene title="head, tail, wc, file">
Altri strumenti rapidi per capire un file senza leggerlo tutto:

- **head** mostra le **prime** righe (10 di default)
- **tail** mostra le **ultime** righe (10 di default)
- **-n 3** dopo head o tail sceglie il numero di righe
- **wc -l** conta le **righe**
- **file** dice di che **tipo** è un file

<Log lines={[
  "studente@lab:~/indagine$ head -n 2 registro.log",
  "09:01 login ok utente=anna",
  "09:05 login ok utente=marco",
  "studente@lab:~/indagine$ tail -n 2 registro.log",
  "09:13 login fallito utente=admin",
  "09:20 logout utente=anna",
  "studente@lab:~/indagine$ wc -l registro.log",
  "6 registro.log",
  "studente@lab:~/indagine$ file registro.log",
  "registro.log: ASCII text",
]} />

<Callout kind="trucco">
`tail -f registro.log` mostra le ultime righe e **continua ad aggiornarsi** man mano che ne arrivano di nuove: è come guardare un registro in diretta. Si ferma con **Ctrl+C**.
</Callout>
