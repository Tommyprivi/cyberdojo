<Scene title="Le liste">
Una **lista** è una sequenza ordinata di valori tra parentesi quadre, separati da virgole. Gli indici funzionano come per le stringhe: partono da 0, `-1` è l'ultimo, `[a:b]` esclude `b`.

```python
ips = ["203.0.113.9", "198.51.100.4", "203.0.113.9", "192.0.2.77"]
print(len(ips))
print(ips[0])
print(ips[-1])
print(ips[1:3])
```

Output:

```text
4
203.0.113.9
192.0.2.77
['198.51.100.4', '203.0.113.9']
```

<Callout kind="attenzione">
Chiedere un indice che non esiste, per esempio `ips[10]`, dà l'errore `IndexError: list index out of range`. Con 4 elementi gli indici validi sono 0, 1, 2 e 3.
</Callout>

<Scene title="I metodi delle liste">
A differenza delle stringhe, una lista si **può modificare**. I metodi più usati:

```python
porte = [80, 22, 443]
porte.append(8080)
porte.sort()
print(porte)
print(22 in porte)
porte.remove(80)
print(porte)
print(porte.count(22))
```

Output:

```text
[22, 80, 443, 8080]
True
[22, 443, 8080]
1
```

- `append(x)` aggiunge in fondo
- `remove(x)` toglie la prima occorrenza di `x`
- `sort()` ordina la lista **sul posto**
- `count(x)` conta quante volte compare `x`
- `x in lista` risponde True o False

<Callout kind="attenzione">
`sort()` modifica la lista e **restituisce None**. Quindi `print(porte.sort())` stampa `None`, non la lista ordinata. Per avere una copia ordinata usa `sorted(porte)`.
</Callout>

<Scene title="I dizionari">
Un **dizionario** associa una **chiave** a un **valore**, tra parentesi graffe: come una rubrica, dove il nome (la chiave) porta al numero (il valore). Le chiavi non si ripetono.

```python
host = {"nome": "server-dati", "porta": 22, "attivo": True}
print(host["nome"])
host["porta"] = 2222
host["os"] = "linux"
print(host)
print(host.get("utente", "sconosciuto"))
```

Output:

```text
server-dati
{'nome': 'server-dati', 'porta': 2222, 'attivo': True, 'os': 'linux'}
sconosciuto
```

- `d[chiave]` legge un valore; `d[chiave] = valore` lo cambia o lo aggiunge
- `d.get(chiave, predefinito)` legge senza rischi: se manca dà il valore predefinito
- `chiave in d` controlla se la **chiave** esiste (non il valore)

<Callout kind="attenzione">
`host["utente"]` con una chiave che non c'è dà `KeyError: 'utente'`. Usa `.get()` quando non sei sicuro che la chiave esista.
</Callout>

Per scorrere un dizionario si usa `.items()`, che dà chiave e valore insieme:

```python
porte = {"ssh": 22, "http": 80, "https": 443}
for nome, numero in porte.items():
    print(nome, "->", numero)
```

Output:

```text
ssh -> 22
http -> 80
https -> 443
```

<Scene title="Contare gli indirizzi">
Ora hai tutto per rispondere a Marta. Il dizionario avrà come chiave l'indirizzo e come valore **quante volte è comparso**.

```python
ips = ["203.0.113.9", "198.51.100.4", "203.0.113.9", "192.0.2.77", "203.0.113.9"]
conteggio = {}
for ip in ips:
    if ip in conteggio:
        conteggio[ip] += 1
    else:
        conteggio[ip] = 1
print(conteggio)
```

Output:

```text
{'203.0.113.9': 3, '198.51.100.4': 1, '192.0.2.77': 1}
```

Con `.get()` il ciclo si accorcia: `conteggio[ip] = conteggio.get(ip, 0) + 1` fa la stessa cosa in una riga. E per segnalare chi compare tre volte o più:

```python
for ip, n in conteggio.items():
    if n >= 3:
        print("sospetto:", ip, n)
```

Output:

```text
sospetto: 203.0.113.9 3
```

<Recap xp={20}>
- Una lista è ordinata e modificabile: indici da 0, slice `[a:b]`, metodi `append`, `remove`, `sort`, `count`.
- Un dizionario associa chiavi a valori: si legge con `d[k]` o `d.get(k, x)` e si scorre con `.items()`.
- Per contare le occorrenze: dizionario vuoto, ciclo, `conteggio[x] = conteggio.get(x, 0) + 1`.
- Caso chiuso: l'indirizzo 203.0.113.9 compare tre volte, quindi finisce tra i sospetti di Marta.
</Recap>
