<Scene title="Che cos'è un socket">
Un **socket** è la «presa» attraverso cui un programma manda e riceve dati in rete: un indirizzo IP più una porta. Il modulo `socket` di Python ti permette di crearne uno.

- Il **server** crea una presa, la lega a una porta (`bind`), si mette in attesa (`listen`) e accetta chi arriva (`accept`).
- Il **client** crea una presa e si collega al server (`connect`).

C'è un dettaglio: la rete trasporta **byte**, non testo. Perciò il testo va convertito: `encode()` lo trasforma in byte prima dell'invio, `decode()` lo riporta a testo dopo la ricezione.

```python
dati = "ciao".encode("utf-8")
print(dati)
print(dati.decode("utf-8"))
print(len(dati))
```

Output:

```text
b'ciao'
ciao
4
```

La `b` davanti indica che sono byte e non una stringa. Quattro lettere, quattro byte.

Vuoi vedere server e client spiegati da un'altra voce? Qui sono costruiti con lo stesso modulo.

<Scene title="Il server">
Salva questo programma in un file `server.py` e lancialo con `python3 server.py`. Resta in attesa di **un** messaggio, lo mostra e risponde.

```python
import socket

HOST = "127.0.0.1"
PORT = 5050

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as server:
    server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server.bind((HOST, PORT))
    server.listen(1)
    print("In ascolto su", HOST, PORT)
    conn, indirizzo = server.accept()
    with conn:
        dati = conn.recv(1024)
        testo = dati.decode("utf-8")
        print("Ricevuto:", testo)
        conn.sendall(("ECO: " + testo).encode("utf-8"))
```

`AF_INET` significa indirizzi IPv4 e `SOCK_STREAM` significa **TCP**, il protocollo affidabile che hai incontrato nelle reti. `recv(1024)` legge **al massimo** 1024 byte. `accept()` si ferma finché non arriva un client, quindi all'inizio il programma sembra «bloccato»: è normale.

<Callout kind="curiosita">
La riga con `SO_REUSEADDR` evita l'errore «Address already in use» se rilanci il server subito dopo averlo fermato.
</Callout>

<Scene title="Il client">
Apri un **secondo terminale**, salva `client.py` e lancialo **dopo** che il server è in ascolto.

```python
import socket

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as client:
    client.connect(("127.0.0.1", 5050))
    client.sendall("ciao SOC".encode("utf-8"))
    risposta = client.recv(1024).decode("utf-8")
    print("Risposta:", risposta)
```

Nel terminale del **server** vedrai:

```text
In ascolto su 127.0.0.1 5050
Ricevuto: ciao SOC
```

E nel terminale del **client**:

```text
Risposta: ECO: ciao SOC
```

<Callout kind="attenzione">
Se lanci il client **prima** del server, nessuno ascolta sulla porta 5050 e Python dà `ConnectionRefusedError`: connessione rifiutata. Non è un guasto: ricordati l'ordine, prima il server.
</Callout>

Hai appena visto con i tuoi occhi cosa significa «porta aperta»: è un programma in ascolto. Se lo fermi, la porta si chiude.

<Scene title="Automatizzare: rinominare e riassumere">
Il secondo compito di Marta è noioso, e per questo perfetto da automatizzare. Primo: rinominare dei file. Lo script crea una cartella di prova con tre file e li rinomina aggiungendo un prefisso.

```python
from pathlib import Path

cartella = Path("prova")
cartella.mkdir(exist_ok=True)
for numero in range(1, 4):
    (cartella / f"log{numero}.txt").write_text("OK\n", encoding="utf-8")

for file in sorted(cartella.glob("log*.txt")):
    nuovo = file.with_name("vecchio_" + file.name)
    file.rename(nuovo)
    print(file.name, "->", nuovo.name)
```

Output:

```text
log1.txt -> vecchio_log1.txt
log2.txt -> vecchio_log2.txt
log3.txt -> vecchio_log3.txt
```

Eseguilo **una volta sola**, nella cartella di prova: se lo ripeti, cancella prima la cartella `prova` creata da lui.

Secondo: riassumere un log. Questa funzione conta quante righe hanno esito `OK` e quante `FAILED`, usando il file `accessi.log` della lezione precedente.

```python
def riassumi(percorso):
    conteggio = {"OK": 0, "FAILED": 0}
    with open(percorso, encoding="utf-8") as f:
        for riga in f:
            parti = riga.split()
            if len(parti) > 1 and parti[1] in conteggio:
                conteggio[parti[1]] += 1
    return conteggio

print(riassumi("accessi.log"))
```

Output:

```text
{'OK': 2, 'FAILED': 2}
```

<Scene title="Tocca a te, e poi cron">
Uno script utile gira **da solo**. Nel modulo sul terminale Linux hai conosciuto **cron**, il programma che esegue comandi a orari fissi. Una riga di `crontab -e` che lancia il riassunto ogni giorno alle 06:30:

```text
30 6 * * * /usr/bin/python3 /home/ada/riassunto.py >> /home/ada/riassunto.out 2>&1
```

I cinque campi sono, nell'ordine: minuto, ora, giorno del mese, mese, giorno della settimana. Con `30 6` significa le 06:30; gli asterischi significano «sempre».

<Callout kind="attenzione">
Cron non parte dalla cartella dello script: usa sempre **percorsi assoluti**, sia per Python sia per il file, e anche dentro lo script. E scrivi l'output in un file, altrimenti non sai se è andato bene.
</Callout>
