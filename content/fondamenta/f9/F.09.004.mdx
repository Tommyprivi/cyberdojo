<Scene title="if e else">
L'istruzione `if` esegue un blocco di righe **solo se la condizione è vera**. Le regole sono due: la riga finisce con i **due punti**, e il blocco va **rientrato** di 4 spazi.

```python
tentativi = 7
if tentativi > 5:
    print("ALLARME")
print("fine controllo")
```

Output:

```text
ALLARME
fine controllo
```

La seconda `print` non è rientrata, quindi non fa parte dell'`if`: viene eseguita sempre. Con `else` si aggiunge ciò che accade quando la condizione è falsa:

```python
tentativi = 3
if tentativi > 5:
    print("ALLARME")
else:
    print("tutto nella norma")
```

Output:

```text
tutto nella norma
```

<Callout kind="regola">
In Python il **rientro** non è estetica: è la sintassi. Le righe rientrate allo stesso modo formano un blocco. Convenzione: 4 spazi.
</Callout>

<Say who="assistente">Se Python protesta con IndentationError, guarda gli spazi a inizio riga: quasi sempre è lì.</Say>
</Scene>

<Scene title="I confronti">
La condizione è un'espressione che dà **True** o **False**. Si ottiene con i confronti:

- `==` uguale
- `!=` diverso
- `>` maggiore, `>=` maggiore o uguale
- `<` minore, `<=` minore o uguale

```python
print(22 == 22)
print(22 != 80)
print(5 >= 5)
print("22" == 22)
```

Output:

```text
True
True
True
False
```

L'ultimo è falso: il testo `"22"` e il numero `22` sono tipi diversi, quindi non sono uguali. Ricordi la lezione sui tipi?

<Callout kind="attenzione">
`=` **assegna**, `==` **confronta**. Scrivere `if porta = 22:` è un `SyntaxError`: Python capisce che volevi confrontare e te lo segnala.
</Callout>

Vuoi sentirlo spiegare da un'altra voce? Meno di sei minuti.

<Scene title="elif: più strade">
Quando le strade sono più di due si aggiunge `elif` («altrimenti se»). Python controlla le condizioni **dall'alto verso il basso**, esegue il primo blocco vero e salta tutti gli altri.

```python
porta = 443
if porta == 22:
    print("accesso remoto (SSH)")
elif porta == 80 or porta == 443:
    print("web")
else:
    print("da controllare")
```

Output:

```text
web
```

Ecco il rapporto di Marta, risolto. Con `porta = 3389` stamperebbe `da controllare`.

<Callout kind="trucco">
`else` non ha condizione: è la strada di tutto il resto. Mettilo sempre per ultimo.
</Callout>

<Say who="assistente">Un'idea per ricordare: elif è un «se invece», e viene letto solo se il se precedente era falso.</Say>
</Scene>

<Scene title="and, or, not">
Le condizioni si combinano con tre parole:

- `and`: **tutte** e due devono essere vere
- `or`: **almeno una** deve essere vera
- `not`: **capovolge** il risultato

```python
tentativi = 12
ip_noto = False
if tentativi > 10 and not ip_noto:
    print("blocca")
else:
    print("osserva")
```

Output:

```text
blocca
```

Più di 10 tentativi **e** indirizzo non noto: si blocca. Se l'indirizzo fosse noto, `not ip_noto` sarebbe falso e si stamperebbe `osserva`.

**L'ordine conta.** Livello di allarme in base ai tentativi: si parte sempre dalla soglia più alta.

```python
tentativi = 25
if tentativi >= 50:
    livello = "critico"
elif tentativi >= 20:
    livello = "alto"
elif tentativi >= 5:
    livello = "medio"
else:
    livello = "basso"
print(livello)
```

Output:

```text
alto
```

Se avessi messo prima `>= 5`, 25 sarebbe finito subito in «medio» e gli altri `elif` non sarebbero mai stati letti.

<Say who="sensei">Dalla soglia più alta alla più bassa. Il primo vero vince, il resto non si guarda.</Say>

<Scene title="Rapporto finale">
<Recap xp={20}>
- `if`, `elif` ed `else` scelgono un blocco: due punti in fondo alla riga e rientro di 4 spazi.
- `==` confronta, `=` assegna; `and`, `or`, `not` combinano le condizioni.
- Il primo ramo vero vince: metti le soglie dalla più alta alla più bassa.
</Recap>
