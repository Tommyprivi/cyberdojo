<Scene title="Che cos'è Python">
**Python** è un linguaggio di programmazione. Lo scegliamo perché si legge quasi come l'inglese, funziona su Linux, Windows e macOS ed è usatissimo in sicurezza e in amministrazione di sistemi.

Python è un linguaggio **interpretato**: un programma chiamato **interprete** legge il tuo testo e lo esegue un'istruzione alla volta, dall'alto verso il basso. Non devi fare altro.

<Callout kind="curiosita">
Il nome non viene dal serpente: viene dal gruppo comico britannico «Monty Python». Per questo negli esempi di Python trovi spesso riferimenti a quegli sketch, come «spam» e «eggs» (uova).
</Callout>

<Callout kind="regola">
Questo corso usa **Python 3.11 o più nuovo**. Sul terminale Linux si controlla con `python3 --version`. Su Windows il comando di solito è `py` oppure `python`.
</Callout>

Vuoi vedere Python spiegato da un'altra voce?

<Scene title="Due modi per farlo partire">
**Primo modo: la shell interattiva.** Scrivi `python3` nel terminale. Compare il simbolo `>>>`: l'interprete aspetta un comando e risponde subito.

```text
$ python3
>>> print("Ciao, SOC")
Ciao, SOC
>>> 2 + 3
5
>>> exit()
```

È perfetta per provare una riga e vedere cosa succede. Si esce con `exit()`.

**Secondo modo: un file.** Scrivi le istruzioni in un file di testo che finisce con `.py`, per esempio `ciao.py`, e lo fai eseguire:

```text
$ python3 ciao.py
```

<Callout kind="trucco">
Una riga da provare: shell interattiva. Un programma da conservare e rilanciare: file `.py`.
</Callout>

<Say who="sensei">Prima si prova nella shell. Quando funziona, si salva in un file. Così non perdi mai il lavoro.</Say>

<Scene title="print e commenti">
La funzione `print()` mostra un valore sullo schermo. Il testo va tra virgolette, i numeri no. Più valori, separati da virgola, vengono scritti con uno spazio in mezzo.

Una riga che comincia con `#` è un **commento**: Python la salta. Serve a chi legge il programma, cioè anche a te fra un mese.

```python
# saluto del turno di notte
print("Turno di notte: inizio")
print("Righe da controllare:", 3)   # il numero resta un numero
```

Output:

```text
Turno di notte: inizio
Righe da controllare: 3
```

<Callout kind="attenzione">
Python distingue **maiuscole e minuscole**. Se scrivi `Print("ciao")` ottieni `NameError: name 'Print' is not defined`. Se dimentichi di chiudere le virgolette ottieni un `SyntaxError`: la riga non è scritta secondo le regole del linguaggio.
</Callout>

<Say who="assistente">Gli errori non sono una bocciatura. Python ti dice il tipo e la riga: leggi l'ultima riga del messaggio, di solito basta quella.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- Python è un linguaggio interpretato: l'interprete esegue il codice riga per riga.
- Si prova una riga nella shell interattiva (`python3`, prompt `>>>`) e si conserva un programma in un file `.py` da lanciare con `python3 file.py`.
- `print()` mostra valori, `#` apre un commento; maiuscole e virgolette contano.
- Caso chiuso: per il conteggio mattutino del log di Marta si usa Python, salvato in un file `.py` e lanciato con `python3 file.py`.
</Recap>
