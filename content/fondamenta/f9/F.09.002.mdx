<Scene title="Una variabile è un'etichetta">
Pensa a una scatola con un'etichetta. Il valore sta dentro, il nome è scritto fuori. Si crea con il segno `=`:

```python
porta = 22
ip = "203.0.113.9"
tentativi = 40
print(ip, porta, tentativi)
```

Output:

```text
203.0.113.9 22 40
```

<Callout kind="attenzione">
In Python `=` significa «metti questo valore in questa scatola», non «è uguale a». Per confrontare due valori si usa `==`, lo vedremo nella lezione sulle decisioni.
</Callout>

**Regole dei nomi:** lettere, numeri e trattino basso `_`; non si comincia con un numero; niente spazi; maiuscole e minuscole contano (`Porta` e `porta` sono due variabili diverse). Meglio nomi chiari: `tentativi_falliti` è meglio di `t`.

<Say who="assistente">Un valore può cambiare nel tempo. Scrivi `tentativi = 41` e la scatola contiene il nuovo valore: quello vecchio sparisce.</Say>
</Scene>

<Scene title="I quattro tipi base">
Ogni valore ha un **tipo**. Python lo capisce da solo, ma tu devi saperlo, perché con tipi diversi si possono fare cose diverse.

- **int**: numero intero, come `22` o `-3`
- **float**: numero con la virgola (che in Python è un punto), come `0.75`
- **str**: testo, sempre tra virgolette, come `"ssh"`
- **bool**: vero o falso, solo `True` o `False` (con la maiuscola)

La funzione `type()` ti dice di che tipo è un valore:

```python
print(type(22))
print(type(0.75))
print(type("ssh"))
print(type(True))
```

Output:

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

<Scene title="Fare i conti">
Con i numeri si calcola. Gli operatori da conoscere sono `+`, `-`, `*`, `/` (divisione), `//` (divisione intera), `%` (resto) e `**` (potenza).

```python
tentativi = 40
print(tentativi + 2)
print(tentativi / 8)
print(tentativi // 3)
print(tentativi % 3)
```

Output:

```text
42
5.0
13
1
```

<Callout kind="attenzione">
La divisione `/` dà **sempre un float**: `40 / 8` fa `5.0`, non `5`. Se ti serve la parte intera della divisione usa `//`; se ti serve il resto usa `%`.
</Callout>

<Callout kind="curiosita">
Anche il testo si può «moltiplicare»: `"ab" * 3` dà `ababab`. E si può sommare con un altro testo: `"ssh" + "d"` dà `sshd`. Ma non si somma un testo con un numero.
</Callout>

<Say who="assistente">Il resto `%` è più utile di quanto sembri: serve per sapere se un numero è pari, per esempio.</Say>
</Scene>

<Scene title="Cambiare tipo, e gli errori tipici">
Se una variabile contiene il **testo** `"22"` e ci sommi un numero, Python si ferma:

```python
porta = "22"
print(porta + 1)
```

L'ultima riga del messaggio d'errore dice:

```text
TypeError: can only concatenate str (not "int") to str
```

**TypeError** significa «tipo sbagliato per questa operazione». Si risolve convertendo:

```python
porta = "22"
print(int(porta) + 1)
print("Porta: " + str(22))
```

Output:

```text
23
Porta: 22
```

Le funzioni di conversione sono `int()`, `float()`, `str()` e `bool()`. Attenzione ai casi limite: `int(3.9)` dà `3` (taglia, non arrotonda) e `int("ventidue")` dà `ValueError`: il testo non è un numero.

<Say who="sensei">Quando vedi TypeError, chiediti: di che tipo è ciascun valore? Quasi sempre uno dei due è testo.</Say>
</Scene>
