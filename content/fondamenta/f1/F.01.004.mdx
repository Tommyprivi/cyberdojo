<Scene title="La fattura che non è una fattura">

<Scene title="Il file e la sua estensione">
Un **file** è un insieme di dati salvato con un nome, di solito sul disco. Ne hai migliaia: foto, documenti, programmi.

Le ultime lettere del nome, dopo l'ultimo punto, sono l'**estensione**: `.jpg`, `.docx`, `.txt`, `.exe`. Dicono al sistema **che tipo di file è** e con quale programma aprirlo.

<Callout kind="trucco">
Cambiare l'estensione **non converte** il file. Rinominare `foto.jpg` in `foto.txt` cambia solo il nome: il contenuto è sempre una foto, ma il sistema prova ad aprirla come testo.
</Callout>

<Say who="assistente">Su Windows le estensioni sono spesso nascoste. Conviene mostrarle: così non ti fai ingannare dai nomi.</Say>
</Scene>

{/* screen */}

<Scene title="Il programma e il processo">
Un **eseguibile** è un file che contiene istruzioni che la CPU può eseguire. È un **programma**. Su Windows ha spesso estensione `.exe`.

Mentre è chiuso, il programma è solo un file sull'armadio (il disco). Quando lo avvii, il sistema lo copia nella RAM e lo fa lavorare: ora è un **processo**.

<Callout kind="regola">
**Programma** = il file sul disco. **Processo** = quel programma **in esecuzione**. Aprendo due volte lo stesso programma ottieni due processi.
</Callout>

<Say who="sensei">Ecco la risposta al caso. Un file con estensione finale .exe è un programma. Aprirlo vuol dire farlo girare con i tuoi permessi.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- Un file è un insieme di dati con un nome; l'estensione dice il tipo, ma non converte nulla.
