<Scene title="Selettore di elemento">
Il selettore più semplice usa il **nome del tag**: colpisce tutti gli elementi di quel tipo.

```css
p {
  color: #333333;
}
h2 {
  text-align: center;
}
```

Va bene per le regole generali («tutti i paragrafi hanno questo colore»). Non va bene quando vuoi distinguere un paragrafo dall'altro.

Per **raggruppare** più selettori nella stessa regola, separali con una virgola:

```css
h1, h2, h3 {
  color: darkred;
}
```

<Say who="assistente">La virgola significa «e»: titoli h1 e h2 e h3, tutti con lo stesso colore.</Say>
</Scene>

<Scene title="Classi e id">
Per distinguere gli elementi, in HTML si dà loro un nome con un attributo, e in CSS lo si richiama.

```html
<p class="avviso">Il corso del 12 marzo è al completo.</p>
<p id="orari">Apertura: martedì e giovedì.</p>
```

```css
.avviso {
  color: darkred;
}
#orari {
  font-style: italic;
}
```

- Una **classe** si scrive con il **punto**: `.avviso`. Più elementi possono avere la stessa classe, e un elemento può avere più classi, separate da spazi: `class="avviso grande"`.
- Un **id** si scrive con il **cancelletto**: `#orari`. Deve essere **unico**: in una pagina un id si usa su un solo elemento.

<Callout kind="regola">
Nell'HTML il nome si scrive **senza** punto e senza cancelletto (`class="avviso"`). Il punto e il cancelletto servono solo nel CSS.
</Callout>

<Say who="sensei">Per lo stile usa le classi quasi sempre. L'id lo tieni per ciò che nella pagina esiste una volta sola.</Say>
</Scene>

<Scene title="Combinare i selettori">
Due combinazioni ti servono subito.

**Elemento dentro un altro** (discendente): due selettori separati da uno spazio.

```css
nav a {
  color: white;
}
```

Significa: «tutti i link `a` che si trovano **dentro** un elemento `nav`». I link fuori dal `nav` non cambiano.

**Elemento con una classe precisa**: il nome del tag attaccato alla classe, senza spazi.

```css
p.avviso {
  color: darkred;
}
```

Significa: «solo i paragrafi che hanno la classe `avviso`». Un titolo con la stessa classe non viene colpito. Attenzione alla differenza: `p .avviso` (con lo spazio) vuol dire «un elemento con classe avviso **dentro** un paragrafo».

<Scene title="Rapporto finale">
<Recap xp={20}>
- Il selettore di elemento usa il nome del tag e colpisce tutti gli elementi di quel tipo.
- La classe si scrive con il punto (`.avviso`) e si può usare su molti elementi; l'id con il cancelletto (`#orari`) è unico nella pagina.
- Con la virgola si raggruppano più selettori; con lo spazio si indica «dentro» (`nav a`).
- Nell'HTML il nome si scrive senza punto e senza cancelletto.
- Caso chiuso: Lucia ha dato la classe `avviso` solo al paragrafo giusto e ha colorato quello, lasciando neri gli altri.
</Recap>
