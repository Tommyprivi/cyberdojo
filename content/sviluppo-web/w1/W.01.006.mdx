<Scene title="Dove si scrive il codice">
Lucia ha aperto il programma di videoscrittura che usa per le lettere, ha scritto la sua prima pagina con tanto di grassetti e l'ha salvata. Il browser mostra solo righe di simboli strani.

Il codice è **testo semplice**: solo caratteri, senza grassetti, colori o immagini. Serve un programma fatto per scriverlo.

La domanda del caso: **con quale programma e in quale ordine si lavora a un sito?**

<Say who="sensei">Il codice è testo puro. Un programma di videoscrittura ci aggiunge cose invisibili che il browser non sa leggere.</Say>
</Scene>

{/* screen */}

<Scene title="L'editor di codice">
Un **editor di codice** è un programma per scrivere testo semplice, con aiuti pensati per chi programma: righe numerate, colori diversi per ogni parte del codice, suggerimenti e correzione di molti errori di battitura.

Scelte gratuite e diffuse:
- **Visual Studio Code**: gratuito, per Windows, Mac e Linux. È il più usato.
- **Notepad++**: gratuito, solo per Windows, leggero.
- **Il Blocco note** (o simili): va bene per una prova, ma non ha aiuti.

  left={{ title: "Programma di videoscrittura", points: ["Salva formattazione nascosta", "Cambia le virgolette in modo «intelligente»", "Il browser non capisce il file"] }}

/>

<Callout kind="attenzione">
Le virgolette «intelligenti» dei programmi di videoscrittura (curve, come “ciao”) **non sono** quelle del codice (dritte, come "ciao"). Un codice con virgolette curve non funziona.
</Callout>

<Say who="assistente">Non cercare l'editor perfetto. Scegline uno, usalo per tutto il corso e imparane le scorciatoie.</Say>
</Scene>

{/* screen */}

<Scene title="La cartella del progetto">
Un sito è fatto di più file. Tienili tutti in **una cartella sola**, che si chiama *cartella del progetto*, per esempio `bottega-lucia`. Dentro metti sottocartelle ordinate.

<Log lines={[
  "bottega-lucia/",
  "  index.html     la pagina principale",
  "  css/",
  "    stile.css    l'aspetto",
  "  js/",
  "    script.js    il comportamento",
  "  img/",
  "    vaso.jpg     le immagini",
]} caption="Una struttura semplice e ordinata." />

Il file `index.html` ha un nome speciale: quando un browser chiede una cartella senza dire quale file, i server mandano di solito proprio `index.html`.

<Say who="sensei">Prima l'ordine, poi il codice. Un progetto con file sparsi diventa un incubo dopo una settimana.</Say>
</Scene>

{/* screen */}

<Scene title="Come si chiamano i file">
Sul server i nomi dei file contano più che sul tuo computer. Le regole d'oro:

- tutto in **minuscolo**: su molti server `Vaso.jpg` e `vaso.jpg` sono file diversi;
- **niente spazi**: usa il trattino, come in `corso-ceramica.html`;
- **niente accenti** né simboli strani;
- l'**estensione** dice che tipo di file è: `.html`, `.css`, `.js`, `.jpg`.

<Callout kind="trucco">
Se sei in dubbio, usa solo lettere minuscole, numeri e trattini. Non sbagli mai.
</Callout>

<Callout kind="attenzione">
Su Windows le estensioni spesso sono nascoste. Un file chiamato `index.html.txt` sembra `index.html` ma è un file di testo. Attiva «Mostra estensioni nomi file» nelle opzioni della cartella.
</Callout>

<Say who="assistente">Quasi metà dei «non funziona!» dei principianti sono nomi di file sbagliati. Controllali per primi.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- Il codice è testo semplice: si scrive con un editor di codice, non con un programma di videoscrittura.
- Un progetto sta in una sola cartella, con sottocartelle ordinate per stile, script e immagini.
- Nomi di file: minuscole, niente spazi né accenti, estensione corretta.
- Caso chiuso: la pagina di Lucia non funzionava perché era stata salvata dal programma di videoscrittura.
</Recap>
