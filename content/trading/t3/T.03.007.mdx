<Scene title="Medie con rolling ed ewm">
**pandas** è la libreria Python per le tabelle e le serie temporali. Una **Series** è una colonna di numeri con un indice.

- `rolling(N).mean()` calcola la **SMA** su una finestra di N valori;
- `ewm(span=N, adjust=False).mean()` calcola la **EMA** con α = 2 ÷ (N + 1).

```python
import pandas as pd

close = pd.Series([10, 12, 14, 16, 18, 20], name="close")
sma3 = close.rolling(3).mean()
ema3 = close.ewm(span=3, adjust=False).mean()
print(sma3.tolist())
print(ema3.tolist())
```

<Log lines={[
  "[nan, nan, 12.0, 14.0, 16.0, 18.0]",
  "[10.0, 11.0, 12.5, 14.25, 16.125, 18.0625]",
]} />

I due `nan` iniziali ci sono perché la finestra di 3 non è ancora piena. I numeri sono gli stessi che abbiamo calcolato a mano nelle lezioni precedenti: se non tornano, c'è un errore.

<Scene title="Il segnale e shift(1)">
Un segnale semplice: **1** se la chiusura è sopra la SMA, **0** altrimenti. Un confronto con `nan` dà sempre `False`, quindi i primi giorni valgono 0.

```python
signal = (close > sma3).astype(int)
position = signal.shift(1)
print(signal.tolist())
print(position.tolist())
```

<Log lines={[
  "[0, 0, 1, 1, 1, 1]",
  "[nan, 0.0, 0.0, 1.0, 1.0, 1.0]",
]} />

`shift(1)` **sposta i valori di una riga avanti nel tempo**: la posizione di oggi usa il segnale di **ieri**. È così che si evita il **look-ahead bias**: usare un'informazione di oggi per un'operazione già decisa.

<Callout kind="regola">
Il segnale calcolato sulla chiusura di oggi può essere usato solo da domani: `position = signal.shift(1)`.
</Callout>

<Say who="assistente">Il look-ahead è come correggere il compito guardando la soluzione. Sembra andar benissimo, ma non hai imparato niente.</Say>

<Scene title="RSI e bande di Bollinger">
Per l'**RSI** servono le variazioni (`diff`), i guadagni e le perdite (`clip`), e le loro medie. Qui, per semplicità, usiamo una **media semplice** su 5 variazioni, come nella lezione sull'RSI (la versione di Wilder, con smussamento, dà numeri leggermente diversi).

```python
close = pd.Series([100, 103, 101, 105, 104, 106])
delta = close.diff()
gain = delta.clip(lower=0)
loss = (-delta).clip(lower=0)
avg_gain = gain.rolling(5).mean()
avg_loss = loss.rolling(5).mean()
rsi = 100 - 100 / (1 + avg_gain / avg_loss)
print(round(avg_gain.iloc[-1], 1), round(avg_loss.iloc[-1], 1), round(rsi.iloc[-1], 1))
```

<Log lines={[
  "1.8 0.6 75.0",
]} />

`diff()` lascia `nan` nella prima riga: il primo giorno non ha un giorno precedente con cui confrontarsi. Per le **bande di Bollinger** attenzione alla deviazione standard: `rolling().std()` usa `ddof=1` di default, mentre la formula con divisore n si scrive `ddof=0`.

```python
close = pd.Series([2, 4, 4, 4, 5, 5, 7, 9])
mid = close.rolling(8).mean()
dev = close.rolling(8).std(ddof=0)
upper = mid + 2 * dev
lower = mid - 2 * dev
print(mid.iloc[-1], round(dev.iloc[-1], 2), round(upper.iloc[-1], 2), round(lower.iloc[-1], 2))
```

<Log lines={[
  "5.0 2.0 9.0 1.0",
]} />

<Say who="sensei">Gli stessi numeri che hai calcolato a mano: 75, e bande 1 e 9. Se il codice dice altro, il codice ha torto.</Say>

<Scene title="ATR con pandas">
Il True Range ha tre colonne di valori: si mettono vicine con `pd.concat` e si prende il **massimo di ogni riga** con `max(axis=1)`.

```python
high = pd.Series([102, 105, 105])
low = pd.Series([99, 100, 101])
close = pd.Series([101, 103, 102])
prev = close.shift(1)
tr = pd.concat([high - low, (high - prev).abs(), (low - prev).abs()], axis=1).max(axis=1)
print(tr.tolist())
print(tr.mean())
```

<Log lines={[
  "[3.0, 5.0, 4.0]",
  "4.0",
]} />

Il primo giorno ha solo `high - low` (3.0), perché manca la chiusura di ieri e `max` ignora i `nan`. In pratica l'ATR si calcola con `tr.rolling(14).mean()`.

<Callout kind="curiosita">
Le librerie come pandas-ta o TA-Lib hanno già questi indicatori. Conviene usarle **dopo** averli capiti: così puoi controllare che diano i numeri che ti aspetti.
</Callout>
