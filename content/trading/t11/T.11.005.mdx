<Scene title="Che cos'è la classificazione">
Prevedere se domani il prezzo sale (1) o no (0) è una **classificazione binaria**: la risposta è una categoria tra due.

Il modello più semplice è la **regressione logistica**. Nonostante il nome, **classifica**: dà una **probabilità** (da 0 a 1) che domani salga. Se è sopra la **soglia** (di solito 0,5) dice «sale», altrimenti «non sale».

È un modello **semplice**, con pochissima libertà di adattarsi al rumore: in finanza è una qualità. Un modello con migliaia di parametri impara il passato a memoria.

<Callout kind="curiosita">
Se la probabilità è 0,51 e la soglia 0,5, il modello dice «sale», ma con pochissima sicurezza. Alzare la soglia a 0,7 significa dire «sale» meno spesso, solo quando è più convinto.
</Callout>

<Scene title="Il codice, con ordine">
Supponiamo di avere la tabella `df` già pronta (feature e target, in ordine di data, senza NaN, come nelle lezioni precedenti).

```python
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler

X = df[["r", "media2", "vol5"]]        # feature
y = df["target"]                        # 1 = domani sale, 0 = no

taglio = int(len(df) * 0.8)             # 80% più vecchio per addestrare
X_tr, X_te = X.iloc[:taglio], X.iloc[taglio:]
y_tr, y_te = y.iloc[:taglio], y.iloc[taglio:]

scaler = StandardScaler().fit(X_tr)     # solo dal passato
modello = LogisticRegression().fit(scaler.transform(X_tr), y_tr)
baseline = DummyClassifier(strategy="most_frequent").fit(X_tr, y_tr)

print("modello :", modello.score(scaler.transform(X_te), y_te))
print("baseline:", baseline.score(X_te, y_te))
```

<Scene title="La matrice di confusione">
Sui 100 giorni di Sara, la **matrice di confusione** conta i casi:

| | previsto «sale» | previsto «non sale» |
|---|---|---|
| è salito davvero | 20 | 22 |
| non è salito | 23 | 35 |

Calcoli, uno alla volta:

- giorni saliti davvero: 20 + 22 = **42**; non saliti: 23 + 35 = **58**; totale 100;
- giorni indovinati: 20 + 35 = **55**, quindi accuratezza **55%**;
- baseline «dico sempre non sale»: 58 giorni su 100, quindi **58%**.

Il modello di Sara fa **peggio** della risposta più banale: 55% contro 58%.

<Callout kind="attenzione">
Questo succede spesso con classi sbilanciate: dire sempre la classe più frequente dà già un buon risultato. L'accuratezza non dice quanto si guadagna o si perde nei giorni sbagliati, né i costi.
</Callout>
