<Scene title="Il codice, passo per passo">
Ecco il backtest completo con pandas (Python 3.11+, pandas 2.x). Ogni riga fa una sola cosa.

```python
import pandas as pd

prezzi = pd.Series([100, 102, 101, 104, 106, 105, 103, 101, 104, 107])
rend = prezzi.pct_change().fillna(0)          # rendimento semplice giornaliero
media = prezzi.rolling(3).mean()              # media mobile a 3 giorni
segnale = (prezzi > media).astype(int)        # 1 se sopra la media
posizione = segnale.shift(1).fillna(0)        # si usa il segnale di ieri
scambi = posizione.diff().abs().fillna(0)     # 1 quando si compra o si vende
lordo = posizione * rend                      # rendimento senza costi
netto = lordo - scambi * 0.002                # costo 0,2% a ogni scambio

print(f"Strategia lorda: {(1 + lordo).prod() - 1:.2%}")
print(f"Strategia netta: {(1 + netto).prod() - 1:.2%}")
print(f"Buy and hold:    {(1 + rend).prod() - 1:.2%}")
print(f"Scambi: {int(scambi.sum())}")
```

Convenzioni: rendimenti **semplici**, composti con `(1 + r).prod() - 1`.

Con la posizione spostata, la strategia è investita solo in tre giorni: giorno 4 (da 104 a 106, **+1,92%**), giorno 5 (da 106 a 105, **-0,94%**) e giorno 9 (da 104 a 107, **+2,88%**).

- Lordo: 1,0192 × 0,9906 × 1,0288 = circa 1,0387, cioè **+3,87%**.
- Scambi: compra il giorno 4, vende il giorno 6, compra il giorno 9. Sono **3**, a 0,2% ciascuno: 0,6% di costi in totale, applicati ai giorni in cui avvengono.
- Netto: **+3,26%**. I costi hanno tolto circa 0,6 punti percentuali.
- Buy and hold: da 100 a 107, cioè **+7,00%**.

<Callout kind="attenzione">
I rendimenti giornalieri si **compongono**, non si sommano: 1,92 - 0,94 + 2,88 darebbe 3,86, un numero diverso e, sui periodi lunghi, molto più sbagliato.
</Callout>

<Scene title="Riproduci il calcolo">
Rifai il conto con Python puro, senza pandas, per vedere dove nasce ogni numero. Ci sono quattro giorni con un movimento: i tre giorni investiti (4, 5 e 9) e il giorno 6, in cui si vende e si paga il costo senza guadagnare nulla.

<PythonTerminal code={"rend = [0.0192, -0.0094, 0.0, 0.0288]
costi = [0.002, 0.0, 0.002, 0.002]
lordo = 1.0
netto = 1.0
for r, c in zip(rend, costi):
    lordo = lordo * (1 + r)
    netto = netto * (1 + r - c)

print(round(netto - 1, 4))"} />
