<Scene title="Il file caricato per sbaglio">
Marta carica il suo progetto su un sito di condivisione del codice, per mostrarlo a un amico. Nel file `bot.py` c'è una riga: `CHIAVE = "chiave-finta-1234"`.

Il progetto è pubblico. Chiunque può leggere quella riga. Con una chiave vera, **chi la trova può fare quello che la chiave permette**.

La domanda del caso: **dove si tiene una chiave, e che cosa si fa se è finita nel posto sbagliato?**

<Scene title="Che cos'è una chiave API">
Una **chiave API** è una password per programmi. Il broker la dà a te; il tuo programma la manda a ogni richiesta, di solito in un header:

<Log lines={[
  "GET /paper/v1/account",
  "Authorization: Bearer <la-tua-chiave>",
]} />

Chi ha la chiave **è** te, per il broker. Per questo:

- si tiene **segreta**, come una password;
- si dà **un permesso alla volta**: chiavi diverse per cose diverse;
- si può **revocare** e rifare in qualsiasi momento.

<Callout kind="regola">
Nel corso usiamo **solo chiavi dell'ambiente demo**. Una chiave di un conto con denaro vero non va mai usata negli esercizi.
</Callout>

<Say who="assistente">Una chiave demo che trapela è una seccatura. Una chiave reale che trapela è un guaio serio.</Say>
</Scene>

<Scene title="Fuori dal codice">
Il segreto va **fuori** dal file. Il posto più semplice è una **variabile d'ambiente**: un valore che il sistema tiene per te e che il programma legge al volo.

```python
import os

chiave = os.environ.get("BROKER_PAPER_KEY")
if chiave is None:
    raise SystemExit("Manca la variabile BROKER_PAPER_KEY: mi fermo.")
```

Altre buone abitudini:

- un file `.env` **fuori dal progetto condiviso** (o elencato in `.gitignore`, che dice a Git di non salvarlo);
- in azienda, un **gestore di segreti** (un servizio fatto per custodire chiavi);
- mai in chat, mai in email, mai in uno screenshot.

<Scene title="Permessi minimi">
Quando crei una chiave, il broker ti chiede che cosa può fare. Regola: **il minimo che serve**.

- Un programma che **legge** prezzi e saldo: chiave di **sola lettura**.
- Un programma che invia ordini demo: chiave demo con permesso di ordine, ma **solo demo**.
- Mai permessi di prelievo o di trasferimento: il corso non ne ha bisogno.

Una funzione utile: **non stampare mai la chiave intera**. Provala:

<PythonTerminal code={"def maschera(chiave):\n    return chiave[:4] + '****'\n\nprint(maschera('abcd1234efgh'))"} />

Risultato atteso: `abcd****`.

<Callout kind="trucco">
Se la chiave è di sola lettura, anche chi la rubasse potrebbe al massimo guardare. Il danno possibile dipende dai permessi.
</Callout>

<Say who="assistente">Quando dubiti, togli un permesso. Si può sempre riaggiungere.</Say>
</Scene>

<Scene title="Rapporto finale">
<Recap xp={20}>
- Una chiave API è una password per programmi: chi la ha è te, per il broker.
- La chiave sta fuori dal codice (variabile d'ambiente, .env ignorato da Git, gestore di segreti), con permessi minimi e mai stampata intera.
- Se trapela: revoca subito, chiave nuova, controllo dei registri. Cancellare il file non basta.
</Recap>
